# 問句庫索引

## 一、固定流程

1. 讀取 `company-standard.md`，依案件類型及受詢問者角色選定公司標準範本。
2. 讀取 `common.md`，只啟用符合身分及程序條件的題目。
3. 依 gate1 的人、事、時、地、物、行為、因果選擇候選罪章檔。
4. 公司題目完整保留；語意相同時不再加入本庫題目。
5. 依序加入 `legal_core`、`evidence_gap`、`distinguishing`、`aggravating` 題目。
6. 問句總量依案件實際缺口裁剪；不得為填滿題庫而全部展開。
7. 被害人以代號表示只觸發公司內部婦幼路由，非法定要件，不能單獨決定罪名或程序。

## 二、公司標準已涵蓋類型

詳見 `company-standard.md`。目前已確認有通用被害人、通用涉嫌人、移送涉嫌人、家暴、違反保護令、跟騷、性騷擾雙方、兒少性剝削、性侵害及性影像範本。

## 六、覆蓋範圍與限制

刑法分則各章均已有路由與章內核心或區分問句。這表示 Gate2 能路由及蒐集要件事實，不表示每一條文均建立獨立固定題組，也不表示個案法律結論已確認。罕見條文採章內補充題並由承辦人依具體事實選用；不得整章展開，以免超過 8 頁及造成重複詢問。

## 七、代號規則

- 問句代號須全庫唯一。
- 類別：`C`核心、`S`補充、`R`補強、`D`區分、`A`加重、`N`涉嫌人端、`W`證人端。
- 新增代號：`NS`國安國交、`JI`司法公正、`PD`公共危險、`WM`度量衡、`GR`祀典墳墓、`AC`農工商、`OP`鴉片、`AB`墮胎。
- 題目必須容許不知道、不確定、不理解或不願回答；敏感題依必要性啟用。
