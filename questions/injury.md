# 傷害罪問句檔（v1）

## 一、要件與區分

**條文要點**
- §277 I：傷害人之身體或健康者，處五年以下有期徒刑、拘役或五十萬元以下罰金。
- §277 II：犯前項之罪，因而致人於死者，處無期徒刑或七年以上有期徒刑；致重傷者，處三年以上十年以下有期徒刑。
- §278 I：使人受重傷者，處五年以上十二年以下有期徒刑。
- §278 II：犯前項之罪因而致人於死者，處無期徒刑或十年以上有期徒刑。
- §278 III：第一項之未遂犯罰之。

**客觀要件**：傷害他人身體或健康；§278 為使人受重傷。
**主觀要件**：傷害的故意（包括直接或間接故意）。

**與本章相近之罪的區分（由 AI 依事實判斷）**
- **過失傷害（§284）**：確認注意義務、可預見性、違反內容與傷害結果。
- **恐嚇危害安全（§305）**：以言語或行為恐嚇，未造成身體傷害。
- **妨害自由（§302、§304）**：限制行動自由，未造成身體傷害。
- **正當防衛或緊急避難**：屬於阻卻違法事由，需由承辦人依事實判斷，本檔不列為罪章問句。

## 二、要素對照（對應 gate1）

| 要素 | 傷害需要取得的事實 | 對應問句 |
|---|---|---|
| 人 | 行為人、被害人、雙方關係 | I-C-05、I-C-09 |
| 事 | 衝突經過、攻擊行為、傷害結果 | I-C-03、I-C-04、I-C-06 |
| 時 | 攻擊時間、就醫時間、發現時間 | I-C-04、I-C-06 |
| 地 | 攻擊地點、就醫地點 | I-C-04 |
| 物 | 使用的工具、器械 | I-C-03、I-C-07 |
| 行為 | 攻擊的部位與方式、力度、反擊 | I-C-03、I-C-07、I-C-08 |
| 因果 | 衝突起因、傷害程度、死亡或重傷的因果 | I-C-02、I-C-08、I-C-10 |

## 三、被害人端

### 核心問句（每案必問）

- **I-C-01**（人）：你與行為人是否認識？雙方之間的關係為何？
- **I-C-02**（因果）：衝突或傷害發生前，雙方發生了什麼事？起因為何？
- **I-C-03**（事、行為）：行為人如何攻擊你？請依順序說明其動作、使用的部位與方式。
- **I-C-04**（時、地）：攻擊發生的時間與地點為何？
- **I-C-05**（人）：行為人的身分與特徵為何？若不知道，請說明你所看見的特徵。
- **I-C-06**（事）：你受傷的部位與情形為何？傷勢如何？
- **I-C-07**（物）：攻擊時是否使用了任何工具或器械？若有，名稱與特徵為何？
- **I-C-08**（行為）：你當時是否有反擊？若有，反擊的方式與傷害的結果為何？
- **I-C-09**（人）：是否有其他人在場？在場人的身分為何？
- **I-C-10**（因果）：傷害的結果為何？是否就醫？就醫的醫院、診斷與診斷證明是否可以提供？

### 補充問句（查證身分、文件與來源，依案件需要使用）

- **I-S-01**（人）：若被害人為未成年人、身心障礙者或受其他監護的人，請說明其法定代理人或監護人的身分與聯絡方式。
- **I-S-02**（物）：就醫紀錄、診斷證明、醫療費用收據是否可以提供？
- **I-S-03**（事）：是否有保護令、和解書、調解紀錄或先前的糾紛紀錄？

### 補強問句（佐證與後續）

- **I-R-01**（事、地、時）：現場或附近是否有監視器或其他影像？是否已調閱？
- **I-R-02**（人）：是否有目擊者？可以提供哪些聯絡方式？
- **I-R-03**（物）：攻擊使用的工具或現場的痕跡是否已保存或採證？
- **I-R-04**（事）：是否曾報案、通報，或向其他機關提出過紀錄？
- **I-R-05**（事）：傷害發生前後，是否有通訊紀錄、對話紀錄可以佐證？

### 區分問句（候選罪章為過失傷害、恐嚇危害安全、妨害自由、正當防衛時使用）

- **I-D-01**（過失）：行為人是否有故意攻擊你的意思？還是因為意外或過失造成？
- **I-D-02**（恐嚇）：行為人是否只以言語或行為威脅，而未實際接觸或造成傷害？
- **I-D-03**（妨害自由）：行為人是否限制了你的行動，而未造成傷害？
- **I-D-04**（正當防衛）：你當時是否有受到不法的攻擊？行為人的攻擊是否已經停止？

### 加重問句（候選罪章為 §277 II 或 §278 時使用）

- **I-A-01**（§277 II）：傷害是否造成死亡？死亡的時間與原因為何？
- **I-A-02**（§277 II、§278）：傷害是否造成重傷？重傷的情形與醫療意見為何？
- **I-A-03**（§278 I）：行為人是否有使你受重傷的意圖或預見？

## 四、涉嫌人端（gate4 或 gate5 使用）

- **I-N-01**（人、時、地）：你於何時、在何處與對方發生衝突？
- **I-N-02**（因果）：衝突的起因為何？你與對方之前有無糾紛？
- **I-N-03**（行為）：你如何與對方接觸？你做了哪些動作？使用的部位與方式為何？
- **I-N-04**（物）：你是否使用了工具或器械？
- **I-N-05**（因果）：你當時的目的為何？你是否預期會造成對方傷害？
- **I-N-06**（事）：衝突後，你是否有離開現場？是否有救助或通報？
- **I-N-07**（人）：是否有其他人參與？其角色為何？
- **I-N-08**（事）：你是否有受傷？受傷的情形為何？

## 五、證人端（有需要時使用）

- **I-W-01**：你於何時、在何處看到衝突或傷害的經過？
- **I-W-02**：你與行為人或被害人是否認識？有無利害關係？

## 六、禁止引導自我檢核

- 問句沒有預設結論（例如「你被打了嗎？」改為「你受傷的部位與情形為何？」）。
- 問句沒有預設行為人的故意（例如「對方是故意的嗎？」改為「行為人當時的目的為何？」）。
- 問句沒有使用「毆打」「嫌犯」「加害人」等定性用語，改用「攻擊」「行為人」「對方」。
- 問句一次只問一件事。
- 每題都有「不知道／不確定」的回答空間。

## 七、核對結果與待核對事項

**已核對（tw-legal-rag get_law_article，現行條文）**
- §277 I、II；§278 I、II、III 的文字與本檔條文要點一致。

**適用限制**
- 正當防衛（§23）、緊急避難（§24）與重傷定義（§10 IV）已核對；是否符合仍由承辦人依事實判斷。
- 條文僅為現行版本，不含行為時法。
- **I-D-10**（§279）：衝突前立即發生哪些言詞或行為？行為人何時得知、何時反應？
- **I-A-10**（§280、§281）：雙方親屬關係如何確認？如未造成傷勢，實際發生哪些強暴動作？
- **I-D-11**（§282）：是否有人提出傷害請求、表示同意、自傷意念或尋求協助？原話、時間與當時身心狀態為何？
- **I-D-12**（§283）：現場聚集何人？各自位置、行為及是否助勢如何確認？死亡或重傷由何資料確認？
- **I-D-13**（§284）：行為人當時負有何種注意義務？可以採取哪些措施、實際採取哪些措施？
- **I-A-11**（§286）：被害人行為時年齡為何？涉及哪些反覆或持續行為、營利情形及傷亡結果？
- **I-D-14**（§287）：涉及 §277 I、§281 或 §284 時，告訴意願另依 `complaint.md` 確認；公務員執行職務犯 §277 I 者除外。
