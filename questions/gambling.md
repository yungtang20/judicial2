# 賭博罪問句檔（v1）

## 一、要件與區分

**條文要點**
- §266 I：在公共場所或公眾得出入之場所賭博財物者，處五萬元以下罰金。
- §266 II：以電信設備、電子通訊、網際網路或其他相類之方法賭博財物者，亦同。
- §266 III：前二項以供人暫時娛樂之物為賭者，不在此限。
- §266 IV：犯第一項之罪，當場賭博之器具、彩券與在賭檯或兌換籌碼處之財物，不問屬於犯罪行為人與否，沒收之。
- §268：意圖營利，供給賭博場所或聚眾賭博者，處三年以下有期徒刑，得併科九萬元以下罰金。

**客觀要件**：以財物為賭；§266 為場所或網路方式；§268 為供給場所或聚眾。
**主觀要件**：故意。§268 另需意圖營利。

**與本章與相近之罪的區分（由 AI 依事實判斷）**
- **供人暫時娛樂之物（§266 III）**：以供人暫時娛樂之物為賭，不構成本罪，例如飲料或小物件。需由承辦人依事實判斷財物的性質。
- **詐欺（§339）**：以詐術使人交付財物，與賭博的合意不同。
- **電子遊戲或網路平台**：是否屬於賭博財物，需依實際的財物與規則判斷，本檔未作結論。

## 二、要素對照（對應 gate1）

| 要素 | 賭博罪需要取得的事實 | 對應問句 |
|---|---|---|
| 人 | 參與的人、供給場所的人、聚眾的人 | Z-C-01、Z-N-06 |
| 事 | 賭博的方式、規則、輸贏的經過 | Z-C-03、Z-N-02 |
| 時 | 賭博的時間、查獲的時間 | Z-N-01、Z-C-06 |
| 地 | 賭博的場所或網路平台 | Z-C-04、Z-N-01 |
| 物 | 賭博的財物、器具、彩券 | Z-C-02、Z-N-04 |
| 行為 | 下注、供給場所、聚眾的行為 | Z-N-02、Z-N-05 |
| 因果 | 是否以財物為賭、是否營利 | Z-N-07、Z-N-08 |

## 三、被害人端（賭博罪通常無被害人，以下為有相關人士或權益受損時使用）

### 核心問句

- **Z-C-01**（人）：你與參與賭博的人是否認識？你是否為參與者、供給場所者或其他關係人？
- **Z-C-02**（物）：賭博的財物有哪些？金額或價值為何？
- **Z-C-03**（事）：賭博的方式與規則為何？輸贏的結果如何結算？
- **Z-C-04**（地）：賭博的地點為公開場所、公眾得出入之場所，或是透過網路進行？
- **Z-C-05**（事）：你是如何得知賭博發生的？
- **Z-C-06**（時）：賭博的時間與持續的時間為何？

### 補充問句

- **Z-S-01**（物）：賭博的器具、彩券、籌碼或其他財物是否可以提供？
- **Z-S-02**（人）：若有平台或網路帳號，帳號的名稱與持有人為何？

### 補強問句

- **Z-R-01**（事）：是否有監視器、通訊紀錄、交易紀錄可以佐證？
- **Z-R-02**（人）：是否有其他參與者或知情人？可以提供哪些聯絡方式？

### 區分問句

- **Z-D-01**（供人暫時娛樂）：賭博的物品是否屬於供人暫時娛樂之物，例如飲料或小物件？其價值與性質為何？
- **Z-D-02**（詐欺）：是否有人以詐術使他人交付財物？與賭博的合意是否不同？

### 加重問句（候選罪章含 §268 時使用）

- **Z-A-01**（§268）：行為人是否意圖營利？營利的方式與金額為何？
- **Z-A-02**（§268）：是否有聚集多人參與賭博？人數與場所的性質為何？

## 四、涉嫌人端（gate4 或 gate5 使用）

- **Z-N-01**（時、地）：你於何時、在何處參與賭博？
- **Z-N-02**（行為）：你參與的方式為何？是下注、供給場所，還是聚集他人？
- **Z-N-03**（事）：賭博的規則與輸贏的結果為何？
- **Z-N-04**（物）：賭博使用的財物或器具為何？目前在何處？
- **Z-N-05**（行為）：你是否收取費用、抽成或其他利益？
- **Z-N-06**（人）：其他參與者是誰？你與對方的關係為何？
- **Z-N-07**（因果）：你當時的目的為何？你是否知道賭博為違法？
- **Z-N-08**（因果）：所賭的財物是否屬於供人暫時娛樂之物？其性質與價值為何？

## 五、證人端（有需要時使用）

- **Z-W-01**：你於何時、在何處看到或知道賭博的情形？
- **Z-W-02**：你與行為人是否認識？有無利害關係？

## 六、禁止引導自我檢核

- 問句沒有預設賭博已發生（例如「你有賭博嗎？」改為「你於何時、在何處進行了什麼活動？」）。
- 問句沒有預設財物的性質（例如「是不是賭錢？」改為「該財物的性質與用途為何？」）。
- 問句沒有使用「賭徒」「賭場」「開賭」等定性用語，改用「活動」「場所」「參與者」。
- 每題都有「不知道／不確定」的回答空間。

## 七、核對結果與待核對事項

**已核對（tw-legal-rag get_law_article，現行條文）**
- §266 I、II、III、IV；§268 的文字與本檔條文要點一致。

**適用限制**
- 網路賭博與電子遊戲的認定，需以個案事實與實務見解判斷，本檔未作結論。
- 條文僅為現行版本，不含行為時法。
