# 公共危險罪補充問句

本檔處理放火、決水、交通運輸、爆裂物、毒物與其他公共危險。§185-3、§185-4 仍使用 `drink-driving.md`。先確認具體危險來源，再載入對應問句，不得因結果嚴重即預設犯罪成立。

## 核心與區分問句

- **PD-C-01**（事）：請依時間順序說明現場發生的事情；哪些部分是你親自看到或聽到的？
- **PD-C-02**（時、地）：最早發現異常及危險擴大的時間、地點各為何？不確定時請說明可確認的範圍。
- **PD-C-03**（物）：涉及哪些建築物、交通工具、設備、爆裂物、氣體、毒物或其他物品？目前由何人保管？
- **PD-C-04**（結果）：現場造成哪些人員、財物、交通或公眾安全影響？有何紀錄可確認？
- **PD-D-01**（§173 至 §176）：起火物、延燒路徑及當時是否有人在建築物或交通工具內，各如何確認？
- **PD-D-02**（§178 至 §181）：水源、堤防或防水設備發生何種變化？影響範圍如何確認？
- **PD-D-03**（§183 至 §185-2）：交通工具、軌道、航行設備或公眾往來設備發生何種異常？異常前後的操作與維護紀錄為何？
- **PD-D-04**（§186 至 §187-3）：涉及物質的名稱、數量、來源、保存與使用方式為何？如不確定，鑑驗狀態為何？
- **PD-D-05**（§188 至 §191-1）：蒸氣、電力、瓦斯、槍砲、毒物、污染物或食品等危險來源為何？接觸或流通範圍如何確認？
- **PD-D-06**（§192 至 §194）：檢疫、傳染病、災害防止命令或相關標示的內容、發布機關及送達情形為何？
- **PD-N-01**（涉嫌人端）：你當時做了哪些操作或處置？每一項操作的時間、目的與依據為何？
- **PD-N-02**（涉嫌人端）：你當時知道哪些現場狀況或風險？資訊從何而來？不知道或不確定的部分為何？
- **PD-R-01**（補強）：有哪些監視器、行車紀錄器、操作紀錄、維修紀錄、通聯、鑑驗、消防或醫療資料可供查證？

## 使用限制

- 每案只載入符合具體危險來源的一組區分問句。
- 涉及傷亡時，另載入 `homicide.md` 或 `injury.md` 的結果與因果問句。
- 不以「放火者」「肇事者」等定性稱呼尚未確認身分的人。
