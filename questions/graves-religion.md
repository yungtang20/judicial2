# 褻瀆祀典及侵害墳墓屍體罪問句

- **GR-C-01**（場所）：事件涉及何種壇廟、寺觀、教堂、墳墓或紀念處所？
- **GR-C-02**（活動）：當時正在進行何種喪葬、祭禮、說教或禮拜？
- **GR-C-03**（行為）：請描述現場發生的具體言語與動作。
- **GR-C-04**（物）：涉及屍體、遺骨、遺髮、殮物、遺灰或其他物品中的哪一項？
- **GR-C-05**（狀態）：事件前後的位置、外觀及完整性有何變化？
- **GR-C-06**（時地）：事件何時、在何處發生及被發現？
- **GR-D-01**（§248、§249）：墳墓是否被開啟或挖掘？現場有哪些痕跡？
- **GR-A-01**（§250）：相關死者與行為人間是否為直系血親尊親屬？依據為何？
- **GR-N-01**：你到達現場的原因為何？
- **GR-N-02**：你接觸或移動哪些物品？
- **GR-N-03**：是否取得家屬、管理人或主管機關同意？同意範圍為何？
- **GR-R-01**：是否有墓籍、火化、管理、監視器、鑑識或修復紀錄？

詢問家屬時採最小必要描述，不要求重複觀看或詳述與要件無關的遺體影像。
