# 妨害電腦使用罪問句檔（v1）

## 一、要件與區分

**條文要點**
- §358：無故輸入他人帳號密碼、破解使用電腦之保護措施或利用電腦系統之漏洞，而入侵他人之電腦或其相關設備者，處三年以下有期徒刑、拘役或科或併科三十萬元以下罰金。
- §359：無故取得、刪除或變更他人電腦或其相關設備之電磁紀錄，致生損害於公眾或他人者，處五年以下有期徒刑、拘役或科或併科六十萬元以下罰金。
- §360：無故以電腦程式或其他電磁方式干擾他人電腦或其相關設備，致生損害於公眾或他人者，處三年以下有期徒刑、拘役或科或併科三十萬元以下罰金。
- §361：對於公務機關之電腦或其相關設備犯前三條之罪者，加重其刑至二分之一。

**客觀要件**：無故入侵、取得、刪除、變更或干擾他人的電腦或相關設備；§359、§360 另需致生損害。
**主觀要件**：故意，並且無故（無合法權限）。

**與本章與相近之罪的區分（由 AI 依事實判斷）**
- **妨害秘密（§315-1）**：窺視、竊聽或竊錄，不涉及入侵電腦系統。
- **詐欺（§339）**：以詐術使人交付，不一定涉及入侵系統。
- **毀損（§354）**：毀壞有形物品；電磁紀錄的刪除或變更屬於 §359。

## 二、要素對照（對應 gate1）

| 要素 | 妨害電腦使用需要取得的事實 | 對應問句 |
|---|---|---|
| 人 | 行為人、帳號持有人、設備所有人 | Y-C-01、Y-C-05 |
| 事 | 入侵、取得、刪除、變更、干擾的經過 | Y-C-03、Y-C-04 |
| 時 | 入侵時間、發現時間 | Y-C-04、Y-C-06 |
| 地 | 設備所在地、登入地點 | Y-C-04、Y-C-07 |
| 物 | 設備、帳號、系統、電磁紀錄 | Y-C-02、Y-C-08 |
| 行為 | 登入方式、破解方式、刪除或變更的內容 | Y-C-03、Y-C-08 |
| 因果 | 是否有權限、造成的損害、是否公務機關 | Y-C-09、Y-C-10 |

## 三、被害人端

### 核心問句（每案必問）

- **Y-C-01**（人）：被入侵或受影響的帳號、系統或設備是誰的？使用人為何？
- **Y-C-02**（物，逐項）：被影響的設備有哪些？請說明名稱、用途與所在地。
- **Y-C-03**（事、行為）：你是如何發現異常的？對方是以什麼方式登入、取得、刪除、變更或干擾？
- **Y-C-04**（時、地）：異常發生的時間與登入的地點（網路位址、裝置、地點）為何？
- **Y-C-05**（人）：你是否曾將帳號密碼提供或告知他人？對象為何？
- **Y-C-06**（事）：發現的時間為何？由誰發現？
- **Y-C-07**（地）：登入或操作的來源為何？是否可以辨識？
- **Y-C-08**（物、行為）：被刪除、變更或取得的電磁紀錄為何？其內容與數量為何？
- **Y-C-09**（因果）：你是否授權對方存取或操作該設備或系統？
- **Y-C-10**（因果）：造成的損害為何？是否影響營運、資料、他人或公眾？

### 補充問句（查證身分、文件與來源）

- **Y-S-01**（人）：設備或系統的管理權限、授權範圍為何？是否有書面紀錄？
- **Y-S-02**（事）：系統紀錄、登入紀錄、異常通知、資安通報是否可以提供？
- **Y-S-03**（人）：若被害人為公司或機構，請提供全名、統一編號、負責人與報案人的職務。
- **Y-S-04**（人）：若設備屬於公務機關，請說明機關名稱與管理單位。

### 補強問句（佐證與後續）

- **Y-R-01**（事）：是否已保存系統紀錄、log、截圖或資料備份？
- **Y-R-02**（事）：是否已向相關平台、電信業者或資安單位申請紀錄或通報？
- **Y-R-03**（人）：是否有其他人遭受類似情形？
- **Y-R-04**（事）：是否曾報案、通報，或向其他機關提出過紀錄？

### 區分問句（候選罪章為妨害秘密、詐欺、毀損時使用）

- **Y-D-01**（妨害秘密）：對方是否只是窺視或竊聽，而未入侵系統或變更資料？
- **Y-D-02**（詐欺）：對方是否以詐術使你交付財物？還是以入侵系統的方式取得？
- **Y-D-03**（毀損）：對方是否毀壞有形的設備？還是只變更或刪除電磁紀錄？

### 加重問句（候選罪章含 §361 時使用）

- **Y-A-01**（§361）：被影響的設備是否屬於公務機關？機關名稱與管理單位為何？

## 四、涉嫌人端（gate4 或 gate5 使用）

- **Y-N-01**（人、時、地）：你於何時、以何種裝置或網路位址登入或存取？
- **Y-N-02**（行為）：你是如何取得帳號密碼或進入系統的？是否使用了工具或漏洞？
- **Y-N-03**（事）：你進入後做了什麼？是否取得、刪除、變更或干擾資料？
- **Y-N-04**（因果）：你是否有權限存取該設備或系統？權限來源為何？
- **Y-N-05**（物）：取得的資料或紀錄目前在何處？是否仍保留？
- **Y-N-06**（因果）：你的目的為何？是否有獲利或其他利益？
- **Y-N-07**（人）：是否有其他人參與或提供協助？
- **Y-N-08**（事）：你是否曾在事後刪除自己的紀錄或痕跡？

## 五、證人端（有需要時使用）

- **Y-W-01**：你於何時、在何處看到或知道系統異常或他人操作的情形？
- **Y-W-02**：你與行為人或被害人是否認識？有無利害關係？

## 六、禁止引導自我檢核

- 問句沒有預設入侵或破解已發生（例如「對方駭入你的系統嗎？」改為「系統出現了什麼異常？」）。
- 問句沒有預設行為人的身分或動機。
- 問句沒有使用「駭客」「盜取」等定性用語，改用「登入」「存取」「行為人」。
- 每題都有「不知道／不確定」的回答空間。
- 涉及個人資料的，應依個資保護規定處理，不在問句中要求被害人揭露與案件無關的資料。
