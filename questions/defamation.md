# 妨害名譽罪問句檔（v1）

## 一、要件與區分

**條文要點**
- §309 I：公然侮辱人者，處拘役或九千元以下罰金。
- §309 II：以強暴犯前項之罪者，處一年以下有期徒刑、拘役或一萬五千元以下罰金。
- §310 I：意圖散布於眾，而指摘或傳述足以毀損他人名譽之事者，為誹謗罪，處一年以下有期徒刑、拘役或一萬五千元以下罰金。
- §310 II：散布文字、圖畫犯前項之罪者，處二年以下有期徒刑、拘役或三萬元以下罰金。
- §310 III：對於所誹謗之事，能證明其為真實者，不罰。但涉於私德而與公共利益無關者，不在此限。
- §311：以善意發表言論，而有下列情形之一者，不罰：一、因自衛、自辯或保護合法之利益者；二、公務員因職務而報告者；三、對於可受公評之事，而為適當之評論者；四、對於中央及地方之會議或法院或公眾集會之記事，而為適當之載述者。

**客觀要件**：§309 為公然以言語或行為侮辱；§310 為指摘或傳述足以毀損名譽之事，並意圖散布於眾。
**主觀要件**：故意；§310 另需意圖散布於眾。

**與本章相近之罪的區分（由 AI 依事實判斷）**
- **公然侮辱與誹謗的區別**：§309 是以言語或行為貶損他人人格，§310 是指摘具體事實。
- **恐嚇（§305）**：以加害之事威脅，非以名譽貶損為主。
- **妨害秘密（§315 以下）**：未經同意窺視、竊錄或散布私密內容。

## 二、要素對照（對應 gate1）

| 要素 | 妨害名譽需要取得的事實 | 對應問句 |
|---|---|---|
| 人 | 行為人、被害人、在場或知情的人 | M-C-01、M-C-05 |
| 事 | 言論或行為的內容、經過、傳播經過 | M-C-03、M-C-04 |
| 時 | 言論或行為發生的時間、發現的時間 | M-C-04、M-C-06 |
| 地 | 發生地點、是否公然 | M-C-04、M-C-07 |
| 物 | 文字、圖畫、影音、平台或管道 | M-C-08、M-A-01 |
| 行為 | 言論或行為的方式、是否強暴 | M-C-03、M-A-02 |
| 因果 | 言論的目的、是否有事實依據、是否為真實 | M-C-09、M-C-10 |

## 三、被害人端

### 核心問句（每案必問）

- **M-C-01**（人）：你與行為人是否認識？雙方之間的關係為何？
- **M-C-02**（因果）：雙方之前是否有糾紛？糾紛的內容為何？
- **M-C-03**（事、行為）：行為人說了什麼或做了什麼？請依時間順序說明，並盡量提供原話或內容。
- **M-C-04**（時、地）：言論或行為發生的時間與地點為何？
- **M-C-05**（人）：當時在場或知情的人是誰？是否有人聽到或看到？
- **M-C-06**（事）：你是如何知道此事的？發現的時間為何？
- **M-C-07**（地）：言論或行為發生於公開場所或私人空間？若公開，當時有幾人在場？
- **M-C-08**（物、管道）：言論是以口頭、文字、圖畫、影音或網路管道散布？管道為何？
- **M-C-09**（因果）：行為人所說的內容，你認為指涉的是你嗎？理由為何？
- **M-C-10**（因果）：該內容與你所知的實際情形有哪些相同或不同？可由哪些資料確認？

### 補充問句（查證身分、文件與來源）

- **M-S-01**（事）：言論的截圖、錄音、錄影、網頁連結、貼文紀錄是否可以提供？
- **M-S-02**（人）：網路帳號的名稱、ID 與所有人是否可以查證？
- **M-S-03**（人）：若被害人為公司或機構，請提供全名、統一編號、負責人與報案人的職務。

### 補強問句（佐證與後續）

- **M-R-01**（事、地）：是否有其他人看到、聽到或轉傳該言論？
- **M-R-02**（事）：言論是否仍在網路或其他地方公開？是否已請求移除？結果為何？
- **M-R-03**（事）：是否曾報案、通報，或向其他機關提出過紀錄？
- **M-R-04**（事）：你是否受到了實際的影響，例如工作、生活或聲譽的損害？

### 區分問句（候選罪章為恐嚇、妨害秘密、公然侮辱與誹謗之間的區分時使用）

- **M-D-01**（公然侮辱）：行為人的言論是否為對你人格的貶損，而未指摘具體事實？
- **M-D-02**（誹謗）：行為人的言論是否指摘了具體的事實？事實的內容為何？
- **M-D-03**（善意、不罰）：行為人發表言論的目的為何？是否基於自衛、公共利益或可受公評之事？
- **M-D-04**（恐嚇）：行為人是否以加害你的事來威脅你？
- **M-D-05**（妨害秘密）：行為人的內容是否來自未經你同意而取得的私密資料？

### 加重問句（候選罪章含 §309 II、§310 II 時使用）

- **M-A-01**（§310 II）：言論是以文字或圖畫散布？散布的範圍與管道為何？
- **M-A-02**（§309 II）：侮辱是否以強暴方式進行？強暴的內容為何？

## 四、涉嫌人端（gate4 或 gate5 使用）

- **M-N-01**（人、時、地）：你於何時、在何處說出或做出該言論或行為？
- **M-N-02**（事）：你說了什麼或做了什麼？請依順序說明，並盡量說明原話。
- **M-N-03**（因果）：你的言論或行為的目的為何？
- **M-N-04**（因果）：你所說的內容是否有事實依據？你的依據為何？
- **M-N-05**（事）：你是否曾在公開場所、網路或其他管道散布該內容？
- **M-N-06**（人）：是否有其他人聽到、看到或轉傳？
- **M-N-07**（因果）：你是否曾向被害人說明、道歉或撤回？
- **M-N-08**（物）：你使用的文字、圖畫、影音或帳號是否為你本人所有？

## 五、證人端（有需要時使用）

- **M-W-01**：你於何時、在何處聽到或看到該言論或行為？
- **M-W-02**：你與行為人或被害人是否認識？有無利害關係？

## 六、禁止引導自我檢核

- 問句沒有預設結論（例如「對方誹謗你了嗎？」改為「行為人說了什麼？」）。
- 問句沒有預設內容的事實性或虛假性（例如「這是假的吧？」改為「你認為此言論的事實依據為何？」）。
- 問句沒有使用「誹謗犯」「嫌犯」「造謠」等定性用語，改用「行為人」「言論」「內容」。
- 問句一次只問一件事。
- 每題都有「不知道／不確定」的回答空間。
- 本類問句涉及言論自由，問句必須保持中性，不得因言論內容而預設其為不實或違法。

- 網路散布的管道與平台移除的實務流程，屬於作業規定，需由你機關確認。
- 條文僅為現行版本，不含行為時法。
- **M-D-10**（§312）：被提及者是否已死亡？言詞或內容、傳播環境及知悉者為何？
- **M-D-11**（§313）：具體流言或詐術內容為何？透過何種傳播工具散布，信用受何影響？
