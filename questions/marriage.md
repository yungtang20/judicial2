# 妨害婚姻及家庭罪問句檔（v1）

## 一、要件與區分

**條文要點**
- §237：有配偶而重為婚姻或同時與二人以上結婚者，處五年以下有期徒刑。其相婚者亦同。

**客觀要件**：有配偶而重為婚姻，或同時與二人以上結婚；相婚者亦同。
**主觀要件**：故意。

**與本章與相近之罪的區分（由 AI 依事實判斷）**
- **同居關係與婚姻**：未辦理結婚登記的同居，不構成重婚，需依民法判斷，本檔不作結論。
- **通姦**：§239 已刪除，不列為現行罪名。
- **家庭暴力與保護令**：屬於家庭暴力防治法範圍，本檔不處理。

## 二、要素對照（對應 gate1）

| 要素 | 重婚需要取得的事實 | 對應問句 |
|---|---|---|
| 人 | 行為人、配偶、重婚的對象 | M1-C-01、M1-N-02 |
| 事 | 結婚的經過、登記的經過、發現的經過 | M1-C-03、M1-C-04 |
| 時 | 結婚或登記的時間 | M1-C-04 |
| 地 | 結婚或登記的機關 | M1-C-04 |
| 物 | 婚姻登記文件、戶籍資料 | M1-S-01、M1-R-01 |
| 行為 | 辦理婚姻登記、同時與多人結婚 | M1-C-03、M1-N-03 |
| 因果 | 是否知道對方已有配偶、是否有效婚姻 | M1-C-05、M1-N-04 |

## 三、被害人端（前配偶、受影響的家屬）

### 核心問句（每案必問）

- **M1-C-01**（人）：你與行為人的婚姻關係為何？婚姻的登記時間為何？
- **M1-C-02**（人）：行為人是否在與你婚姻關係存續中，與他人結婚？
- **M1-C-03**（事）：你是如何知道此事的？行為人與他人的婚姻登記經過為何？
- **M1-C-04**（時、地）：重婚登記的時間與機關為何？
- **M1-C-05**（因果）：你是否知道行為人已有配偶的情形？你的依據為何？

### 補充問句（查證身分與文件）

- **M1-S-01**（物）：婚姻登記文件、戶籍謄本是否可以提供？
- **M1-S-02**（人）：你與行為人是否已離婚或婚姻已消滅？離婚的時間與依據為何？

### 補強問句（佐證與後續）

- **M1-R-01**（事）：是否有其他文件、通訊紀錄或證人可以佐證？
- **M1-R-02**（事）：是否曾向機關提出異議或申請更正？結果為何？

### 區分問句（候選罪章為同居、通姦、詐欺時使用）

- **M1-D-01**（同居）：雙方是否只有同居，而未辦理婚姻登記？
- **M1-D-02**（詐欺）：行為人是否以婚姻為名，使他人交付財物？

### 加重問句

- 本條文無獨立加重事由。

## 四、涉嫌人端（gate4 或 gate5 使用）

- **M1-N-01**（人、時、地）：你於何時、在何處辦理結婚登記？
- **M1-N-02**（人）：你與結婚對象的關係為何？
- **M1-N-03**（事）：你當時是否已有配偶？與配偶的婚姻是否仍存續？
- **M1-N-04**（因果）：你是否知道自己在與他人結婚時已有配偶？
- **M1-N-05**（事）：你是否曾向機關提出離婚或婚姻消滅的文件？
- **M1-N-06**（人）：是否有其他人參與或協助辦理登記？
- **M1-N-07**（物）：結婚登記文件是否由你本人簽名或提出？
- **M1-N-08**（因果）：你當時的考量或原因為何？

## 五、證人端（有需要時使用）

- **M1-W-01**：你於何時、在何處知道此事？
- **M1-W-02**：你與行為人或結婚對象是否認識？有無利害關係？

## 六、禁止引導自我檢核

- 問句沒有預設重婚已發生（例如「你重婚了嗎？」改為「你的婚姻登記經過為何？」）。
- 問句沒有使用「小三」「重婚犯」等定性用語，改用「配偶」「結婚對象」「行為人」。
- 每題都有「不知道／不確定」的回答空間。
