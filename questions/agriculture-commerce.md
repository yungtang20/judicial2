# 妨害農工商罪問句

- **AC-C-01**（物）：涉及何種商品、農工必需品、生活必需品、商標或標示？
- **AC-C-02**（數量）：數量、庫存地點及進出貨情形為何？
- **AC-C-03**（價格）：相關期間的售價、報價及市場價格資料為何？
- **AC-C-04**（交易）：何人決定停止銷售、販運、陳列、輸入或標示方式？
- **AC-C-05**（資訊）：曾對外發布哪些資訊？發布管道及原始資料為何？
- **AC-D-01**（§251）：行政院是否公告該物品？不應市銷售的原因及紀錄為何？
- **AC-D-02**（§251）：是否以強暴或脅迫妨害販運？請記錄具體言詞與行為。
- **AC-D-03**（§252）：涉及何種農事水利？原有供水及事件後變化為何？
- **AC-D-04**（§253、§254）：商標或商號的登記資料及商品使用方式為何？
- **AC-D-05**（§255）：商品標示的原產國或品質為何？客觀檢驗或來源文件為何？
- **AC-N-01**：你在採購、庫存、定價、標示或銷售中的職責為何？
- **AC-N-02**：你作成相關決定時依據哪些資料？
- **AC-N-03**：你何時知道登記、產地、品質或市場資訊？
- **AC-R-01**：是否有進銷存、報關、發票、廣告、檢驗或公告資料？

商標法、公平交易法及行政管制可能同時適用；本檔不以行政違規直接推定刑事犯罪。
