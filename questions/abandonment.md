# 遺棄罪問句檔（v1）

## 一、要件與區分

**條文要點**
- §293 I：遺棄無自救力之人者，處六月以下有期徒刑、拘役或三千元以下罰金。
- §293 II：因而致人於死者，處五年以下有期徒刑；致重傷者，處三年以下有期徒刑。
- §294 I：對於無自救力之人，依法令或契約應扶助、養育或保護而遺棄之，或不為其生存所必要之扶助、養育或保護者，處六月以上、五年以下有期徒刑。
- §294 II：因而致人於死者，處無期徒刑或七年以上有期徒刑；致重傷者，處三年以上十年以下有期徒刑。

**客觀要件**：遺棄無自救力之人，或不為其生存所必要之扶助、養育或保護。§294 另需依法令或契約有扶助義務。
**主觀要件**：故意。

**與本章與相近之罪的區分（由 AI 依事實判斷）**
- **§293 與 §294**：§294 的行為人負有法定或契約上的扶助義務；§293 則為一般的遺棄。
- **傷害或殺人**：若有直接傷害或殺害意圖，應另依該罪章判斷。
- **無自救力的認定**：需由承辦人依被害人的年齡、身心狀況判斷。

## 二、要素對照（對應 gate1）

| 要素 | 遺棄罪需要取得的事實 | 對應問句 |
|---|---|---|
| 人 | 無自救力之人、行為人、負有扶助義務的人 | H-C-01、H-C-05 |
| 事 | 遺棄或未扶助的經過、被發現的經過 | H-C-03、H-C-06 |
| 時 | 遺棄的時間、發現時間、扶助中斷的時間 | H-C-04、H-C-06 |
| 地 | 遺棄地點、被發現地點 | H-C-04、H-C-07 |
| 物 | 被遺棄人的身心狀況、生活所需的扶助物 | H-C-02、H-C-08 |
| 行為 | 遺棄的方式、不為扶助的內容 | H-C-03、H-C-08 |
| 因果 | 扶助義務的來源、是否致人死亡或重傷 | H-C-09、H-C-10 |

## 三、被害人端（被遺棄人或其家屬、照護人）

### 核心問句（每案必問）

- **H-C-01**（人）：被遺棄人的年齡與身心狀況為何？是否能自行照顧自己？
- **H-C-02**（物）：被遺棄人在日常生活中所需要的照顧、扶助與物品為何？
- **H-C-03**（事、行為）：行為人如何遺棄被遺棄人，或如何不為其扶助？請依順序說明。
- **H-C-04**（時、地）：遺棄或中斷扶助的時間與地點為何？
- **H-C-05**（人）：行為人與被遺棄人的關係為何？行為人是否有法定或契約上的扶養、照顧義務？
- **H-C-06**（事）：你是如何知道此事的？發現的時間為何？
- **H-C-07**（地）：被遺棄人被發現的地點與當時的情形為何？
- **H-C-08**（物、行為）：被遺棄人當時是否有可以取得的飲食、醫療或照顧？
- **H-C-09**（因果）：是否因此致人死亡或重傷？傷亡的情形與醫療紀錄為何？
- **H-C-10**（因果）：行為人有無提出理由？其理由為何？

### 補充問句（查證身分、文件與來源）

- **H-S-01**（人）：扶養、照顧或監護的依據為何？是否有法院裁定、契約或書面約定？
- **H-S-02**（人）：被遺棄人的戶籍、監護人與其他扶養義務人為何？
- **H-S-03**（事）：醫療紀錄、照護紀錄、社福或衛生單位的通報紀錄是否可以提供？

### 補強問句（佐證與後續）

- **H-R-01**（事、地）：是否有監視器或其他影像？是否已調閱？
- **H-R-02**（人）：是否有其他照顧者、鄰居或目擊者？可以提供哪些聯絡方式？
- **H-R-03**（事）：是否曾向社福、衛生或警政機關通報？結果為何？

### 區分問句（候選罪章為殺人、傷害、妨害自由時使用）

- **H-D-01**（殺人）：行為前後，行為人說了什麼、做了什麼？有哪些資料可用來了解其當時目的？
- **H-D-02**（傷害）：除未提供扶助、養育或保護外，行為人另做了哪些接觸或處置？造成何種結果？
- **H-D-03**（妨害自由）：行為人是否限制了被遺棄人的行動自由？

### 加重問句（候選罪章含 §293 II 或 §294 II 時使用）

- **H-A-01**（§293 II、§294 II）：是否因此致被遺棄人死亡？死亡的時間與原因為何？
- **H-A-02**（§293 II、§294 II）：是否因此致被遺棄人重傷？傷勢與醫療紀錄為何？

## 四、涉嫌人端（gate4 或 gate5 使用）

- **H-N-01**（人、時、地）：你於何時、在何處與被遺棄人相處或負責照顧？
- **H-N-02**（因果）：你對被遺棄人的扶養、照顧義務來源為何？
- **H-N-03**（事、行為）：你是如何離開或不再照顧被遺棄人的？請依順序說明。
- **H-N-04**（物）：被遺棄人當時的飲食、醫療、照顧狀況為何？
- **H-N-05**（因果）：你當時的考量或原因為何？
- **H-N-06**（人）：是否有其他照顧者或協助者？其角色為何？
- **H-N-07**（事）：你是否曾嘗試通報或求助？結果為何？
- **H-N-08**（因果）：你是否知道被遺棄人當時的身心狀況與可能的危險？

## 五、證人端（有需要時使用）

- **H-W-01**：你於何時、在何處看到被遺棄人或行為人的情形？
- **H-W-02**：你與行為人或被遺棄人是否認識？有無利害關係？

## 六、禁止引導自我檢核

- 問句沒有預設遺棄已發生（例如「你把他丟了嗎？」改為「被遺棄人當時的所在與狀況為何？」）。
- 問句沒有預設行為人負有扶助義務（例如「你有義務照顧他嗎？」改為「你與被遺棄人的關係為何？」）。
- 問句沒有使用「棄養」「虐待」等定性用語，改用「不再照顧」「行為人」「被遺棄人」。
- 涉及未成年人或身心障礙者，應依兒少與身障保護規定處理，並通知相關社福單位。
- 每題都有「不知道／不確定」的回答空間。

## 七、核對結果與待核對事項

**已核對（tw-legal-rag get_law_article，現行條文）**
- §293 I、II；§294 I、II 的文字與本檔條文要點一致。

**適用限制**
- 「無自救力」的認定標準需由承辦人依事實判斷。
- 兒童及少年福利與權益保障法、身心障礙者權益保障法等另有規定，本檔未核對。
- 條文僅為現行版本，不含行為時法。
- **A-D-10**（§294-1）：無自救力之人先前有哪些行為、裁判或長期未盡扶養情形？各項時間與證明資料為何？
- **A-A-10**（§295）：雙方是否為直系血親尊親屬關係？如何確認？
