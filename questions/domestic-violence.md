# 家庭暴力案件問句檔（v1，婦幼）

**本檔涉及被害人保護。被害人的姓名、住址等可識別資訊依法不得公開；問句不要求被害人在筆錄中揭露與案件無關的私人資料。**

## 一、要件與區分

**條文要點（§2）**
- 家庭暴力：家庭成員間實施身體、精神或經濟上之騷擾、控制、脅迫或其他不法侵害之行為。
- 家庭暴力罪：家庭成員間故意實施家庭暴力行為而成立其他法律所規定之犯罪。
- 目睹家庭暴力：指看見或直接聽聞家庭暴力。
- 騷擾：指任何打擾、警告、嘲弄或辱罵他人之言語、動作或製造使人心生畏怖情境之行為。
- 跟蹤：指任何以人員、車輛、工具、設備、電子通訊或其他方法持續性監視、跟追或掌控他人行蹤及活動之行為。

**區分**
- 家庭暴力罪本身依其他刑事法律認定（例如傷害、恐嚇、妨害自由、妨害秘密），由該罪章檔判斷。
- 保護令種類、聲請人、緊急聲請及通常保護令內容已依 §9、§10、§12、§14 核對；其餘法院程序仍依個案確認。

## 二、要素對照（對應 gate1）

| 要素 | 需要取得的事實 | 對應問句 |
|---|---|---|
| 人 | 行為人、被害人、家庭成員關係、目睹的兒少 | DV-C-01、DV-C-05 |
| 事 | 暴力或騷擾的種類、經過、次數、持續時間 | DV-C-03、DV-C-04 |
| 時 | 事發時間、持續期間、發現時間 | DV-C-04 |
| 地 | 事發地點（住居所或其他） | DV-C-04 |
| 物 | 工具、財物、證據 | DV-C-06、DV-R-02 |
| 行為 | 身體、精神或經濟上的侵害方式 | DV-C-03、DV-C-07 |
| 因果 | 原因、先前的家暴紀錄、是否有保護令 | DV-C-08、DV-R-03 |

## 三、被害人端

### 核心問句（每案必問）

- **DV-C-01**（人）：你與行為人的關係為何？是否為同居或家庭成員？（僅詢問關係，不要求說明與案件無關的私人資料）
- **DV-C-02**（人）：你是否有同住的子女或其他家屬？是否有目睹或聽聞暴力？
- **DV-C-03**（事、行為）：行為人對你做了什麼？包括身體、言語、經濟或精神上的對待，請依順序說明。
- **DV-C-04**（時、地）：事件發生的時間與地點為何？是否反覆發生？大約的次數與期間為何？
- **DV-C-05**（人）：是否有其他人目睹或聽聞？其身分為何？
- **DV-C-06**（物）：是否有傷勢、物品損壞或其他證據？是否已就醫或拍照？
- **DV-C-07**（行為）：行為人是否有騷擾、跟蹤、控制或經濟上的限制？請說明情形。
- **DV-C-08**（因果）：事件的原因為何？你當時的感受與擔憂為何？
- **DV-C-09**（事）：你是如何通報或求助的？通報的時間與機關為何？

### 補充問句（依被害人保護程序，由承辦人與被害人溝通後決定是否提問）

- **DV-S-01**（人）：是否需要通譯、社工或心理師陪同？
- **DV-S-02**（人）：未成年子女的照顧情形為何？是否需要通報兒少保護？
- **DV-S-03**（人）：是否需要住宿、經濟扶助或其他資源？

### 補強問句（依被害人意願提供）

- **DV-R-01**（事）：是否有驗傷單、醫療紀錄、診斷證明？
- **DV-R-02**（事、物）：是否有訊息、錄音、錄影、照片或其他紀錄？是否已保存？
- **DV-R-03**（事）：是否曾報案、申請保護令或接受過相關服務？文號與結果為何？
- **DV-R-04**（人）：是否有其他知情人（親友、鄰居）可以佐證？

### 區分問句

- **DV-D-01**（一般傷害或恐嚇）：行為人與你是否為家庭成員？若否，依一般刑事罪章處理。
- **DV-D-02**（跟蹤騷擾）：行為是否與性或性別有關，且為持續、違反意願？若是，依跟蹤騷擾防制法處理。

### 加重問句

- 本檔未設獨立加重事由，加重依各刑事罪章與其他法規判斷。

## 四、涉嫌人端（gate4 或 gate5 使用）

- **DV-N-01**（人、時、地）：你與對方的關係為何？是否同住？
- **DV-N-02**（事、行為）：你對對方做了什麼？請依順序說明。
- **DV-N-03**（因果）：事件發生的原因為何？你當時的感受為何？
- **DV-N-04**（事）：是否曾有過類似事件？是否曾被通報或申請保護令？
- **DV-N-05**（人）：是否有未成年子女在場或受影響？
- **DV-N-06**（事）：你是否願意接受加害人處遇、輔導或治療？（僅詢問意願）

## 五、證人端（有需要時使用）

- **DV-W-01**：你於何時、在何處看到或聽到事件？
- **DV-W-02**：你與當事人的關係為何？有無利害關係？

## 六、禁止引導自我檢核

- 問句沒有預設家庭暴力已發生（例如「對方打你嗎？」改為「對方對你做了什麼？」）。
- 問句不使用「施暴者」「加害人」等定性用語，改用「行為人」「對方」。
- 問句不得要求被害人揭露與案件無關的私人或性經歷。
- 被害人的身分資料不得在公開文件中揭露。
- 每題都有「不知道／不願回答」的空間。

## 八、保護令與警察處置（v2，已核對）

- **§9**：民事保護令分為通常保護令、暫時保護令及緊急保護令。
- **§10 I**：被害人得向法院聲請通常保護令、暫時保護令；被害人為未成年人、身心障礙者或因故難以委任代理人者，其法定代理人、三親等以內血親或姻親得代為聲請。
- **§10 II**：檢察官、警察機關或直轄市、縣（市）主管機關得向法院聲請保護令。
- **§12 I**：緊急保護令得以言詞、電信傳真或其他科技設備聲請，並得於夜間或休息日為之。
- **§12 II**：聲請得不記載聲請人或被害人之住居所，僅記載送達處所。
- **§12 III**：被害人要求保密住居所者，法院應以秘密方式訊問，筆錄與資料密封，禁止閱覽。
- **§14 I**：通常保護令的內容，包括禁止實施家庭暴力、禁止騷擾或跟蹤、遷出住居所、遠離特定場所、定必需品使用權、未成年子女權利義務與會面交往、給付租金或扶養費、完成加害人處遇計畫等十六款。
- **§48**：警察人員處理家庭暴力案件，必要時應採取守護住居所、保護至庇護所或醫療機構、告知權利與救濟途徑、查訪並告誡相對人、訪查被害人及提供安全措施等。警察人員處理案件應製作書面紀錄。
- **§49**：醫事人員、社工、教育人員及保育人員，有身心不法侵害之虞者，得請求警察機關提供必要協助。
- **§61**：違反保護令者，為違反保護令罪，處三年以下有期徒刑、拘役或科或併科十萬元以下罰金。
- **§62**：違反 §50 第一項通報義務，或違反 §52 或 §63-1 準用 §52 規定者，由主管機關處六千元以上三萬元以下罰鍰。
- **§63**：違反 §51 第三款（無正當理由撥打專線、妨害公務），經勸阻不聽者，主管機關得處三千元以上一萬五千元以下罰鍰。

**警察端補充問句（v2）**
- **DV-S-04**（事）：警察到場後，是否已守護被害人住居所或採取安全措施？
- **DV-S-05**（事）：是否已告知被害人得行使的權利與救濟途徑？告知的時間與方式為何？
- **DV-S-06**（事）：是否已查訪並告誡相對人？查訪的時間與結果為何？
- **DV-S-07**（事）：是否已製作書面紀錄？紀錄的格式與日期為何？
- **DV-S-08**（事）：是否已通報主管機關（§50，至遲二十四小時）？通報的時間與對象為何？
- **DV-R-05**（事）：被害人是否有保護令？是否有違反保護令的情形？（§61）
- **DV-R-06**（人）：被害人是否要求保密住居所？（§12 III，依規定處理，不寫入公開文件）

## 九、家庭成員範圍（v2，已核對）

- **§3**：本法所定家庭成員，包括下列各員及其未成年子女：一、配偶或前配偶；二、現有或曾有同居關係、家長家屬或家屬間關係者；三、現為或曾為直系血親；四、現為或曾為四親等以內之旁系血親；五、現為或曾為四親等以內血親之配偶；六、現為或曾為配偶之四親等以內血親；七、現為或曾為配偶之四親等以內血親之配偶。

**問句（v2 補充）**
- **DV-C-10**（人）：你與行為人的關係為何？是否屬於配偶、前配偶、同居關係、直系血親、四親等內旁系血親或姻親？（依 §3 逐類判斷，不要求揭露與案件無關的資訊）
