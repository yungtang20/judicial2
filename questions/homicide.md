# 殺人罪問句檔（v1）

**本檔涉及重大案件。死亡案件的現場勘察、相驗、鑑識，屬於刑事相驗程序，問句不取代相驗與鑑定。**

## 一、要件與區分

**條文要點**
- §271 I：殺人者，處死刑、無期徒刑或十年以上有期徒刑。
- §271 II：前項之未遂犯罰之。
- §271 III：預備犯第一項之罪者，處二年以下有期徒刑。
- §272：對於直系血親尊親屬，犯前條之罪者，加重其刑至二分之一。

**客觀要件**：使他人死亡的行為，或其未遂。
**主觀要件**：故意殺人。

**與本章與相近之罪的區分（由 AI 依事實判斷）**
- **傷害致死（§277 II）**：有傷害的故意，但死亡非預期之結果。
- **過失致死（§276）**：著重注意義務、可預見性、違反內容及結果因果。
- **義憤殺人（§273）、殺嬰（§274）**：均已核對；殺嬰問句另見 `infanticide-procuring.md`。
- **受囑託、得承諾、教唆或幫助自殺（§275）**：分別確認意思形成、具體協助及行為時狀態。

## 二、要素對照（對應 gate1）

| 要素 | 殺人需要取得的事實 | 對應問句 |
|---|---|---|
| 人 | 被害人、行為人、親屬關係 | P-C-01、P-C-05 |
| 事 | 攻擊的經過、死亡的經過、發現的經過 | P-C-03、P-C-06 |
| 時 | 死亡時間、發現時間、報案時間 | P-C-04、P-C-06 |
| 地 | 死亡地點、現場 | P-C-04、P-C-07 |
| 物 | 兇器、工具、交通工具 | P-C-08、P-A-01 |
| 行為 | 攻擊的方式、致死的方式、事後處置 | P-C-03、P-C-08 |
| 因果 | 殺意的形成、死亡與行為的因果 | P-C-09、P-N-03 |

## 三、被害人端（死者家屬、目擊者或相關人）

### 核心問句（每案必問）

- **P-C-01**（人）：死者的身分與年齡為何？與你的關係為何？
- **P-C-02**（因果）：死者生前是否與行為人有糾紛、債務或其他衝突？
- **P-C-03**（事、行為）：行為人如何對死者施加行為？請依順序說明。
- **P-C-04**（時、地）：死亡的時間與地點為何？你最後一次見到死者的時間為何？
- **P-C-05**（人）：行為人的身分與你的關係為何？若不知道，請說明你所掌握的資料。
- **P-C-06**（事）：你是如何發現死者死亡或受害的？發現的時間與人為何？
- **P-C-07**（地）：現場的狀況為何？是否有移動或改變？
- **P-C-08**（物）：行為人使用了什麼兇器或工具？該物品目前在何處？
- **P-C-09**（因果）：你是否知道行為人與死者之間的糾紛或動機？

### 補充問句（依相驗程序與家屬權益，由承辦人與家屬溝通後使用）

- **P-S-01**（人）：死者的戶籍、身分證明與親屬關係為何？
- **P-S-02**（事）：死者生前的醫療紀錄、診斷與就醫情形是否可以提供？
- **P-S-03**（人）：是否有需要通譯、社工、心理師或其他專業人員協助？

### 補強問句（佐證與後續）

- **P-R-01**（事、地）：現場或附近是否有監視器或其他影像？是否已調閱？
- **P-R-02**（人）：是否有目擊者或最後接觸死者的人？可以提供哪些聯絡方式？
- **P-R-03**（事）：是否已完成相驗、解剖或鑑識採證？結果為何？
- **P-R-04**（事）：是否有遺書、通訊紀錄或其他文字紀錄？

### 區分問句（候選罪章為傷害致死、過失致死、自殺、義憤殺人時使用）

- **P-D-01**（傷害致死）：行為前後，行為人說了什麼、做了什麼？使用方式、部位、次數及停止原因為何？
- **P-D-02**（過失致死）：死亡是否因過失或意外造成？
- **P-D-03**（自殺）：死者是否有自行結束生命的情形？相關事實為何？
- **P-D-04**（義憤殺人，§273）：事件前立即發生哪些言詞或行為？行為人何時得知、何時反應，中間經過多久？

### 加重問句（候選罪章含 §272 時使用）

- **P-A-01**（§272）：死者是否為行為人的直系血親尊親屬？關係的具體內容為何？

### 預備問句（候選罪章含 §271 III 時使用）

- **P-P-01**（§271 III）：行為人是否有預備犯殺人罪的情形，例如準備兇器、規劃犯罪流程或前往現場踩線？各項準備行為的時間、地點及內容為何？

## 四、涉嫌人端（gate4 或 gate5 使用）

- **P-N-01**（人、時、地）：你於何時、在何處與死者接觸？
- **P-N-02**（因果）：你與死者之間的關係與糾紛為何？
- **P-N-03**（事、行為）：你對死者做了什麼？請依順序說明。
- **P-N-04**（物）：你使用了什麼兇器或工具？目前在何處？
- **P-N-05**（因果）：你當時的目的為何？你是否預期死者會死亡？
- **P-N-06**（事）：事發後，你做了什麼？是否離開現場？是否有救助或通報？
- **P-N-07**（人）：是否有其他人參與或知情？其角色為何？
- **P-N-08**（因果）：你當時是否有精神狀況或其他身心狀況的異常？（依精神鑑定相關規定處理）

## 五、證人端（有需要時使用）

- **P-W-01**：你於何時、在何處看到或知道死者與行為人的互動？
- **P-W-02**：你與行為人或死者是否認識？有無利害關係？

## 六、禁止引導自我檢核

- 問句沒有預設殺意（例如「對方想殺他嗎？」改為「行為人當時的目的為何？」）。
- 問句沒有預設死亡的因果（例如「是他打死的嗎？」改為「死者當時的狀況與經過為何？」）。
- 問句沒有使用「兇手」「殺人犯」等定性用語，改用「行為人」「死者」。
- 涉及家屬的案件，應保持尊重與溫和的語氣，並提供心理支持資源。
- 每題都有「不知道／不確定」的回答空間。

## 八、章內補充問句

- **P-A-10**（§272-1）：被害人行為時年齡為何？是否涉及持續或反覆的凌虐方式？各自證據為何？
- **P-D-10**（§275）：是否有人提出死亡請求、表示同意、自殺意念或尋求協助？原話、時間與當時身心狀態為何？
- **P-D-11**（§275）：他人提供哪些資訊、物品或行動協助？該協助與死亡或未遂結果如何確認？
- **P-D-12**（§276）：行為人當時負有何種注意義務？可以採取哪些措施、實際採取哪些措施，結果如何發生？
