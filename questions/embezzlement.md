# 侵占罪問句檔（v1）

## 一、要件與區分

**條文要點**
- §335 I：意圖為自己或第三人不法之所有，而侵占自己持有他人之物者，處五年以下有期徒刑、拘役或科或併科三萬元以下罰金。
- §335 II：未遂犯罰之。
- §336 I：對於公務上或因公益所持有之物，犯前條第一項之罪者，處一年以上七年以下有期徒刑，得併科十五萬元以下罰金。
- §336 II：對於業務上所持有之物，犯前條第一項之罪者，處六月以上五年以下有期徒刑，得併科九萬元以下罰金。
- §336 III：前二項之未遂犯罰之。
- §337：意圖為自己或第三人不法之所有，而侵占遺失物、漂流物或其他離本人所持有之物者，處一萬五千元以下罰金。

**客觀要件**：行為人「已持有」他人之物（持有的來源合法），再以侵占行為將其據為己有。
**主觀要件**：意圖為自己或第三人不法之所有。

**與本章相近之罪的區分（由 AI 依事實判斷，問句用於取得事實）**
- **竊盜（§320）**：行為人原本不持有該物，是以竊取取得；侵占則是原本已持有。
- **詐欺（§339）**：被害人因受騙而主動交付；侵占的持有來自合法委託或其他合法來源，並非受騙交付。
- **背信（§342）**：§342 已核對；案件涉及為他人處理事務、違背任務並致生損害時，轉入 `fraud.md` 補充題。
- **使用侵占（不法所有意圖不成立）**：僅暫時使用，之後歸還，沒有排除他人所有權的意思。
- **侵占遺失物（§337）**：物品是遺失物、漂流物，或離開本人持有、尚未落入他人管領的物品；與 §335 的持有關係不同。
- **公務、業務侵占（§336）**：持有的原因是公務、公益或業務；需先確定持有的來源，才能判斷適用哪一項。

## 二、要素對照（對應 gate1）

| 要素 | 侵占需要取得的事實 | 對應問句 |
|---|---|---|
| 人 | 行為人、被害人、持有關係的來源 | E-C-05、E-S-01 |
| 事 | 持有的建立經過、侵占行為的經過、發現經過 | E-C-03、E-C-06、E-C-07 |
| 時 | 持有開始時間、侵占行為時間、發現時間 | E-C-04、E-C-06 |
| 地 | 持有地點、行為地點 | E-C-03 |
| 物 | 名稱、數量、特徵、價值、所有權 | E-C-01、E-C-02 |
| 行為 | 如何處分、變賣、藏匿、否認、拒絕返還 | E-C-07、E-C-08 |
| 因果 | 持有的原因、約定、是否同意處分、動機 | E-C-09、E-C-10 |

## 三、被害人端

### 核心問句（每案必問）

- **E-C-01**（物，逐項）：遭侵占的物品有哪些？請逐項說明名稱、數量、特徵（品牌、規格、容量、型號、序號等）。
- **E-C-02**（物，逐項）：每一項物品的價值如何認定？請說明依據，例如售價、購買價格、估價，並說明是否有憑證。
- **E-C-03**（人、地）：該物品是在何時、何地，交由行為人持有或保管的？交付的方式為何？
- **E-C-04**（時）：交付持有的時間為何？交付時的約定或目的為何？
- **E-C-05**（人）：行為人與你的關係為何？行為人持有該物品的身分或職務為何？
- **E-C-06**（事、時）：你是如何發現該物品未被返還或已被處分的？發現的時間為何？
- **E-C-07**（行為）：你是否知道行為人對該物品做了什麼？例如是否變賣、丟棄、使用、藏匿、拒絕返還？若不知道，請說明你所知道的部分。
- **E-C-08**（行為）：你是否曾向行為人要求返還？行為人的回應為何？
- **E-C-09**（因果）：你是否曾同意或授權行為人處分、使用、變賣該物品？若有，同意的範圍與條件為何？
- **E-C-10**（因果）：行為人是否曾就該物品提出任何說明或理由？其說明的內容為何？

### 補充問句（查證身分、文件與來源，依案件需要使用）

- **E-S-01**（人、物）：行為人與你之間是否有書面或口頭約定、契約、收據或借據？持有的依據為何？
- **E-S-02**（人、物）：物品的所有權屬於誰？報案人是否為所有人、受委託人或代理人？若受委託，委託範圍為何？是否有書面授權？
- **E-S-03**（人）：若被害人為公司或機構，請提供全名、統一編號、負責人與報案人的職務。
- **E-S-04**（事、物）：是否有盤點紀錄、帳冊、出貨或領用紀錄，可以確認物品的數量差異？

### 補強問句（佐證與後續）

- **E-R-01**（事、物）：是否有其他文件、通訊紀錄、對話紀錄可以佐證持有與處分的情形？
- **E-R-02**（人）：是否有其他人知道持有或處分的情形？可以提供哪些聯絡方式？
- **E-R-03**（物）：物品目前在何處？是否已找回？若已找回，何時、何地、由誰找回？找回時的狀態為何？
- **E-R-04**（事）：是否曾報案、通報，或向其他機關提出過紀錄？
- **E-R-05**（人、因果）：你與行為人之間是否有糾紛、借貸或其他金錢關係？
- **E-R-06**（物）：除了本次遭侵占的物品外，還有無其他物品曾交由行為人持有且未返還？

### 區分問句（候選罪章為竊盜、詐欺、侵占遺失物、使用侵占、背信時使用）

- **E-D-01**（竊盜）：行為人是否在交付前就已持有該物品？還是他是以取走的方式取得？
- **E-D-02**（詐欺）：行為人是否曾以任何說法使你交付該物品？交付時你的想法為何？
- **E-D-03**（侵占遺失物）：該物品是否曾經遺失、漂流，或離開你的持有？若是，何時、何地、如何離開？
- **E-D-04**（使用侵占）：行為人是否曾將該物品暫時使用後歸還？歸還的時間與狀態為何？
- **E-D-05**（背信）：行為人是否負有處理你事務的責任？其權限與義務為何？（§342 已核對，本題作區分用途）
- **E-D-06**（業務、公務持有）：行為人持有該物品是否與其職務、業務或公務有關？其職務名稱與職掌為何？

### 加重問句（候選罪章為 §336 時使用）

- **E-A-01**（§336 I）：行為人持有該物品是否基於公務或公益？其職務、機關與所負責任為何？
- **E-A-02**（§336 II）：行為人持有該物品是否基於業務？其業務內容與持有的依據為何？

## 四、涉嫌人端（gate4 或 gate5 使用）

- **E-N-01**（人、時、地）：你於何時、在何處取得該物品的持有？持有的依據為何？
- **E-N-02**（因果）：取得持有時，你是否知道該物品的所有人是誰？當時的約定為何？
- **E-N-03**（行為）：取得持有後，你如何處置該物品？是否使用、變賣、丟棄、藏匿或交給他人？
- **E-N-04**（物）：該物品目前在何處？是否仍在你的持有之下？
- **E-N-05**（因果）：你為何要處置該物品？當時的考量為何？
- **E-N-06**（因果）：是否曾經向所有人說明或要求返還？對方的回應為何？
- **E-N-07**（人）：是否有其他人參與處置或知悉此事？
- **E-N-08**（人、時）：你是否曾將該物品交還或補償？交還或補償的時間、方式與內容為何？

## 五、證人端（有需要時使用）

- **E-W-01**：你於何時、在何處看到行為人持有或處置該物品？
- **E-W-02**：你與行為人或被害人是否認識？有無利害關係？

## 六、禁止引導自我檢核

每一題送出前，請確認：

- 問句沒有預設結論（例如「你的東西被侵占了嗎？」改為「該物品目前的狀況為何？」）。
- 問句沒有預設行為人身分或持有的合法性（例如「對方是否擅自拿走？」改為「行為人持有該物品的依據為何？」）。
- 問句沒有使用「侵占」「嫌犯」「詐騙」等定性用語，改用「行為人」「對方」「處置」。
- 問句一次只問一件事，多項物品時使用「逐項」。
- 每題都有「不知道／不確定」的回答空間。
- 補充與補強問句只用於查證與佐證，不取代核心問句。
