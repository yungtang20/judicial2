# 職場與校園性別事件問句檔（v1，婦幼）

**本檔涉及被害人隱私、職場與校園的權力關係。性騷擾與性侵害的詢問應依 `sexual-harassment.md` 的原則進行，問句採最低限度描述。雇主與學校的內部程序，與刑事程序分開，不得以內部調查取代偵查。**

## 一、要件與區分

**條文要點（性別平等工作法）**
- §12 I：性騷擾包括兩類：一、受僱者於執行職務時，任何人以性要求、具有性意味或性別歧視之言詞或行為，對其造成敵意性、脅迫性或冒犯性之工作環境，致侵犯或干擾其人格尊嚴、人身自由或影響其工作表現；二、雇主對受僱者或求職者為明示或暗示之性要求、具有性意味或性別歧視之言詞或行為，作為勞務契約成立、存續、變更或陞遷、考績、獎懲等之交換條件。
- §12 II：權勢性騷擾，指對於因僱用、求職或執行職務關係受自己指揮、監督之人，利用權勢或機會為性騷擾。
- §12 III：受僱者於非工作時間，遭受所屬事業單位之同一人持續性性騷擾，或遭受共同作業之不同事業單位同一人，或最高負責人、僱用人為性騷擾者，亦適用本法。
- §12 IV：性騷擾之認定，應就個案審酌事件背景、工作環境、當事人關係、行為人言詞與行為及相對人之認知等具體事實。
- §12 VI：§13、§13-1、§27 至 §30、§36 至 §38-1 之規定，於性侵害犯罪，亦適用之。
- §12 VII：第一項第一款係由不特定人於公共場所或公眾得出入場所為之者，就性騷擾事件之調查、調解及處罰，適用性騷擾防治法。
- §12 VIII：最高負責人指機關（構）首長、學校校長、行政法人董事長、公營事業機構董事長，或法人、非法人團體之對外代表人等。

**條文要點（§13，雇主義務）**
- §13 I：雇主應採取適當之措施，防治性騷擾之發生；僱用十人以上未達三十人者，應訂定申訴管道；僱用三十人以上者，應訂定防治措施、申訴及懲戒規範，並公開揭示。
- §13 II：雇主知悉性騷擾時，應採取立即有效之糾正及補救措施，包括避免再度發生、提供諮詢或醫療心理資源、調查、對行為人適當懲戒。
- §13 III：雇主查證應秉持客觀、公正、專業原則，給予當事人陳述意見及答辯機會，有詢問必要時，應避免重複詢問。
- §13 IV：雇主接獲被害人申訴時，應通知地方主管機關；經調查認定屬性騷擾者，並應將處理結果通知地方主管機關。

**條文要點（性別平等教育法）**
- §2：本法主管機關，中央為教育部，直轄市及縣（市）為各該政府；警察各級學校之主管機關依其所屬。
- §21 I：中央主管機關應訂定校園性別事件之防治準則，包括學校安全規劃、主動迴避陳報、校園性別事件之處理機制與救濟方法。
- §21 II：學校應依準則訂定防治規定，並公告周知。
- §21 III：學校應積極推動防治教育，每年定期舉辦宣導活動，並評鑑其實施成效。
- §25 I：學校或主管機關處理校園性別事件，應告知當事人及其法定代理人或實際照顧者其得主張之權益及救濟途徑，或轉介相關機構，並提供心理諮商與輔導，必要時提供保護措施、法律協助或社會福利資源。
- §25 II：前項服務，學校或主管機關得委請醫師、臨床心理師、諮商心理師、社會工作師或律師等專業人員為之。
- §25 III：學生為性侵害、性騷擾或性霸凌事件被害人，而非屬本法適用範圍者，學生所屬學校得準用前二項規定。

**區分**
- 職場或校園的性騷擾（§12 I、II）與一般性騷擾（性騷擾防治法 §25）：依場域與關係判斷，§12 VII 規定公眾場所之不特定人行為，適用性騷擾防治法。
- 職場性侵害（刑法性自主，`sexual.md`）與性騷擾：依事實判斷是否屬於性侵害犯罪，§12 VI 規定部分條文亦適用於性侵害犯罪。
- 雇主或學校的內部調查與刑事偵查：兩者並行，內部結果不取代刑事程序。

## 二、要素對照（對應 gate1）

| 要素 | 需要取得的事實 | 對應問句 |
|---|---|---|
| 人 | 被害人、行為人、雇主或學校、權勢關係 | GE-C-01、GE-C-05 |
| 事 | 性要求、性意味言詞或行為、交換條件、經過 | GE-C-03、GE-C-06 |
| 時 | 事發時間、是否在工作或上課時間、通報時間 | GE-C-04、GE-C-07 |
| 地 | 工作場所、學校、宿舍、非工作場所 | GE-C-04、GE-C-08 |
| 物 | 訊息、影像、紀錄、申訴文件 | GE-R-01 |
| 行為 | 言語、行為、交換條件、權勢利用 | GE-C-03、GE-C-05 |
| 因果 | 權勢或機會、對工作或學習的影響、是否依性平程序申訴 | GE-C-05、GE-C-09 |

## 三、被害人端（由受過訓練的人員詢問，依被害人意願）

### 核心問句（每案必問）

- **GE-C-01**（人）：你的身分、職務或就學狀況為何？你與行為人的關係為何？
- **GE-C-02**（人）：你是否為受僱者、求職者或學生？（僅詢問必要資訊）
- **GE-C-03**（事、行為）：行為人做了什麼？是言語、行為、要求，還是其他？請依你願意陳述的範圍說明。
- **GE-C-04**（時、地）：事件發生的時間與地點為何？是否在工作或上課時間？
- **GE-C-05**（因果）：行為人是否對你有指揮、監督、評分、陞遷或其他權勢？是否利用此權勢或機會？
- **GE-C-06**（因果）：行為是否使你的工作或學習環境產生敵意、脅迫或冒犯？你的感受與影響為何？
- **GE-C-07**（時）：你是否在非工作時間或非上課時間遭受持續性的行為？
- **GE-C-08**（地）：行為發生於工作場所、學校、宿舍，還是公共場所？
- **GE-C-09**（事）：你是否已向雇主或學校提出申訴？申訴的時間與結果為何？

### 補充問句（依被害人保護程序與性平程序）

- **GE-S-01**（人）：你是否需要心理諮商、醫療、法律協助或保護措施？（依性平教育法 §25）
- **GE-S-02**（人）：你是否希望由特定性別的人員受理？（依性平與隱私規定）
- **GE-S-03**（事）：雇主或學校是否已通知地方主管機關？（依性平工作法 §13 IV）
- **GE-S-04**（人）：若你為未成年學生，法定代理人或實際照顧者的身分與聯絡方式為何？

### 補強問句

- **GE-R-01**（事）：是否有訊息、通話紀錄、影像、目擊者或其他紀錄可以佐證？
- **GE-R-02**（事）：是否有雇主或學校的申訴紀錄、調查紀錄、懲戒結果？
- **GE-R-03**（人）：是否曾向其他機關反映或申請救濟？

### 區分問句

- **GE-D-01**（一般性騷擾）：行為是否發生於公共場所或公眾得出入場所，而非職場或校園？若是，適用性騷擾防治法（`sexual-harassment.md`）。
- **GE-D-02**（性侵害區分）：對方實際有哪些身體接觸或其他行為？當時以哪些言詞、動作或物品影響你的意願或反應？
- **GE-D-03**（一般職場糾紛）：是否僅為一般工作爭執，而未涉及性或性別相關之言行？

### 加重問句

- **GE-A-01**（§12 II）：行為人是否為權勢者？其指揮、監督關係的具體內容為何？

## 四、涉嫌人端（gate4 或 gate5 使用）

- **GE-N-01**（人、時、地）：你與對方的關係為何？你於何時、在何處與對方接觸？
- **GE-N-02**（事、行為）：你對對方做了什麼？請依順序說明。
- **GE-N-03**（因果）：你是否有對對方的工作、成績或其他利益施加影響？
- **GE-N-04**（因果）：你是否知道對方不同意或感到不適？你的依據為何？
- **GE-N-05**（事）：事後你是否有道歉、和解或其他處理？
- **GE-N-06**（事）：是否曾有類似事件或被申訴？

## 五、證人端（有需要時使用）

- **GE-W-01**：你於何時、在何處看到或知道事件？
- **GE-W-02**：你與當事人的關係為何？有無利害關係？

## 六、禁止引導自我檢核

- 問句沒有預設性騷擾或性侵害已發生。
- 問句不得使用「性騷擾犯」「色狼」「霸凌者」等定性用語，改用「行為人」「相對人」「對方」。
- 問句不要求被害人重複陳述或描述性行為細節。
- 問句不詢問被害人與案件無關的私生活與性經歷。
- 問句不以雇主或學校的內部調查結論取代刑事偵查。
- 每題都有「不知道／不願回答」的空間。
