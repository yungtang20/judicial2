# 偽造有價證券罪問句檔（v1）

## 一、要件與區分

**條文要點**
- §201 I：意圖供行使之用，而偽造、變造公債票、公司股票或其他有價證券者，處三年以上十年以下有期徒刑，得併科九萬元以下罰金。
- §201 II：行使偽造、變造之公債票、公司股票或其他有價證券，或意圖供行使之用而收集或交付於人者，處一年以上七年以下有期徒刑，得併科九萬元以下罰金。
- §202 I：意圖供行使之用，而偽造、變造郵票或印花稅票者，處六月以上五年以下有期徒刑，得併科三萬元以下罰金。
- §202 II：行使偽造、變造之郵票或印花稅票，或意圖供行使之用而收集或交付於人者，處三年以下有期徒刑，得併科三萬元以下罰金。
- §202 III：意圖供行使之用，而塗抹郵票或印花稅票上之註銷符號者，處一年以下有期徒刑、拘役或九千元以下罰金；其行使之者，亦同。
- §203：意圖供行使之用，而偽造、變造船票、火車、電車票或其他往來客票者，處一年以下有期徒刑、拘役或九千元以下罰金；其行使之者，亦同。

**客觀要件**：偽造或變造有價證券、郵票、印花稅票或往來客票；行使、收集或交付。
**主觀要件**：意圖供行使之用。

**與相近之罪的區分（由 AI 依事實判斷）**
- **§201 與 §210、§211（偽造文書）**：有價證券與文書的界線，需依證券的性質判斷。
- **§201 與偽造貨幣（§195）**：貨幣與有價證券不同，依物品判斷。
- **詐欺（§339）**：以偽造的證券使人交付財物，可能與詐欺競合。

## 二、要素對照（對應 gate1）

| 要素 | 需要取得的事實 | 對應問句 |
|---|---|---|
| 人 | 製造者、行使者、收受者、交付者 | SE-C-01、SE-N-02 |
| 事 | 偽造、變造、行使、交付的經過 | SE-C-03、SE-N-03 |
| 時 | 製造時間、行使時間、發現時間 | SE-C-04 |
| 地 | 製造地點、行使地點 | SE-C-04 |
| 物 | 證券的種類、面額、號碼、發行機構 | SE-C-02、SE-N-04 |
| 行為 | 製造、變造、行使、收集、交付、塗抹註銷的方式 | SE-C-03、SE-N-03 |
| 因果 | 是否意圖供行使、收受時是否知情 | SE-C-05、SE-N-05 |

## 三、被害人端（發行機構、受損的人或機關）

### 核心問句（每案必問）

- **SE-C-01**（人）：你的機構或與證券的關係為何？你是否為發行人、受託人或收受人？
- **SE-C-02**（物，逐項）：涉及的證券有哪些？種類、面額、號碼與發行機構為何？
- **SE-C-03**（事、行為）：證券是如何被製造、變造、行使或交付的？請依順序說明。
- **SE-C-04**（時、地）：交付或發現的時間與地點為何？
- **SE-C-05**（因果）：你是如何判斷證券為偽造或變造的？是否經過鑑定？
- **SE-C-06**（事）：你是否曾因此遭受損失？損失的金額與情形為何？

### 補充問句

- **SE-S-01**（物）：證券的真本、號碼登記、發行紀錄是否可以提供？
- **SE-S-02**（人）：若被害人為機構，請提供全名、統一編號與負責人。

### 補強問句

- **SE-R-01**（事）：是否有交易紀錄、收據或監視器可以佐證？
- **SE-R-02**（人）：是否有其他收受或交付的人？可以提供哪些聯絡方式？
- **SE-R-03**（事）：是否曾向主管機關、金融機構或警方反映？

### 區分問句（候選罪章為詐欺、偽造文書、偽造貨幣時使用）

- **SE-D-01**（詐欺）：對方是否以偽造證券使你交付財物？
- **SE-D-02**（偽造文書）：證券是否屬於一般文書？其形式與功能為何？
- **SE-D-03**（偽造貨幣）：證券是否為通用貨幣或紙幣？

### 加重問句

- 本條文無獨立加重事由。

## 四、涉嫌人端（gate4 或 gate5 使用）

- **SE-N-01**（人、時、地）：你於何時、在何處取得或製作證券？
- **SE-N-02**（人）：你與提供或收受證券的人的關係為何？
- **SE-N-03**（事、行為）：你做了什麼？是製造、變造、行使、收集或交付？請依順序說明。
- **SE-N-04**（物）：證券的種類、面額與目前的存放位置為何？
- **SE-N-05**（因果）：你是否知道證券為偽造或變造？你的依據為何？
- **SE-N-06**（人）：是否有其他人參與製造、收集或行使？其角色為何？
- **SE-N-07**（事）：你是否曾將證券用於交易、質押、借款或其他用途？時間與結果為何？

## 五、證人端（有需要時使用）

- **SE-W-01**：你於何時、在何處看到或知道證券的製造、行使或交付？
- **SE-W-02**：你與行為人是否認識？有無利害關係？

## 六、禁止引導自我檢核

- 問句沒有預設證券為偽造（例如「這張股票是假的嗎？」改為「證券的發行資訊與鑑定結果為何？」）。
- 問句沒有使用「假股票」「偽造犯」等定性用語，改用「證券」「行為人」。
- 每題都有「不知道／不確定」的回答空間。
