# Task 6：通用筆錄問句結構分析報告

來源：`review/extracted_excel_questions.md`（新套表，共 532 題基準問句）。
範圍：涉嫌人筆錄、被害人筆錄、證人筆錄三個分頁。
用途：作為未來 LLM 生成完整筆錄的標準骨架（SOP）。

## 1. 涉嫌人通用筆錄骨架

### 1.1 起手式（程序與權利）

- 警方所告知之罪名及權利，你是否清楚？你有無刑案紀錄？
- 你是否具有低收入戶、中低收入戶、原住民或其他依法令得請求法律扶助者之身分？你是否需要通知親屬、法扶或委任律師陪同到場？
- 依據提審法第1條之規定（人民被法院以外之任何機關逮捕、拘禁時，其本人或他人得向逮捕、拘禁地之地方法院聲請提審…前項聲請及第10條之抗告，免徵費用），你是否清楚此規定？是否需要聲請提審？
- 現在時間為 年月日時分時分許，依刑事訴訟法為夜間偵訊時間，你是否同意接受製作夜間警詢筆錄？目前精神狀況是否良好？意識是否清醒？
- 現在時間為 年月日時分時分許，依刑事訴訟法為夜間偵訊時間，警方不得對你詢問製作筆錄，你是否知悉？
- 上記年籍資料是否正確？是否有刑案紀錄？你現在精神狀況是否清楚？
- 警方告知你涉嫌○○罪名及得行使之三項權利，你是否清楚？你是否具有身心障礙、低收入戶、中低收入戶及原住民等身分？是否需要請辯護人及親友到場陪同製作筆錄？
- 現因警力不足，是否同意由警方一人為你製作筆錄？
- 依刑法第57條規定，犯案後之態度將作為檢察官及法官日後審案量刑之依據，你是否清楚？是否願意向警方據實陳述？
- 是否領有身心障礙證明？是否經醫囑使用精神藥物？身障類別、鑑定向度及障礙程度為何？
- 你現在精神狀況如何？是否可以製作詢問紀錄？
- 意圖使公務員登載不實或誣告他人將負刑事責任，你是否清楚？
- 物品是否為你同意並主動交付？且搜索扣押筆錄是否由你親自審視後，並簽名捺印？

### 1.2 基礎事實與指認

- 你今(  )日因何事接受警方製作筆錄？／你今日因何事至本所製作筆錄？
- 你是否知悉於警詢筆錄中做不實陳述須負法律責任？
- 你有無為自己或他人推卸刑責而向警方為不實陳述？
- 警方製作警詢筆錄時，有無全程錄音錄影？
- 警方於偵訊時你所陳述之事實是否為你自由意識下所陳述？警方有無以強暴、脅迫等不正方法對你取供？警方在逮捕你時，有無使你受傷？
- 警方受理被害人報案稱渠所有之物品於案發時、地遭人毀損（竊取等），你是否知悉此事？
- 警方出示監視器畫面供你辨識，畫面中之行為人（男子）是否為你本人？
- 經警方提供你觀看監視器，該物品拿取是否為你本人？（竊盜情境）
- 經警方出示登入紀錄，畫面中所示之登入時間、IP位址是否為你所為？（妨害電腦使用情境）
- 承上，經警方查明被害人所稱與事實不符，你有何解釋？是否有誤認、誤信或受人誤導之情形？
- 警方於製作筆錄時，你的精神狀況如何？意識是否清楚？有無遭警方脅迫或威脅等違法情事？

### 1.3 法條釋明與定性確認

- 毒品危害防制條例第17條第1項規定：「犯第四條至第八條、第十條或第十一條之罪，供出毒品來源，因而查獲其他正犯或共犯者，減輕或免除其刑」；第二項規定：「犯第四條至第八條之罪於偵查及審判中均自白者，減輕其刑」，你是否清楚？
- 你是否知道如主動供出毒品之上游來源，使警方因而破獲者，依法可獲得減刑？
- 依就業服務法第60條規定，若查無非法容留、聘僱或媒介外國人從事工作者及遣送事由可歸責之雇主者，其收容費用應由被遣送之外國人負擔，你是否清楚？
- 依性騷擾防治法第18條規定，因本案係權勢性騷擾以外之性騷擾事件，任一方當事人如有意願進行調解，得以書面或言詞向直轄市、縣（市）社政主管機關申請調解，你是否知悉？你是否有意願申請調解？（如非適用性騷擾防治法，或本案涉及權勢性騷擾，請刪除）
- 依刑事訴訟法第238條：告訴乃論之罪，告訴人於第一審辯論終結前，得撤回其告訴。撤回告訴之人，不得再為同一件事提出告訴，你是否確定要撤回告訴？

### 1.4 收尾式（意願與送達）

- 因本案為告訴乃論之罪，你是否願意配合臺北地檢署進行調解？
- 你事後有無向被害人道歉或採取補救措施？
- 筆錄內容記載有無錯誤？有何意見補充？
- 以上筆錄是否為你自由意識下之陳述？警方有無使用暴力、脅迫、威脅、利誘或其他不正方法向你取供？警方製作筆錄過程中有無全程錄音、錄影？
- 以上筆錄所述登載是否屬實正確？有無其他意見補充？
- 你有無有利之證據可提供警方，或有請求警方調查之處？
- 你是否願意前往商家結帳？是否願意提供明細？
- 你有無向調解委員會聲請調解程序？調解情形為何？
- 你能提供何種資料（事故聯單、初判表、車鑑表、驗傷單）供警方後續偵辦使用？
- 文書送達地址為何？

## 2. 被害人通用筆錄骨架

### 2.1 起手式（程序與權利）

- 你今(12)日因何事接受警方製作筆錄？／你今日因何事至所製作筆錄？
- 上記年籍資料是否正確？目前從事何業？有無前科？
- 真實姓名對照表內之資料是否正確？是否為你本人？
- 你現在精神狀況如何？是否可以製作詢問紀錄？
- 是否領有身心障礙證明？是否經醫囑使用精神藥物？身障類別、鑑定向度及障礙程度為何？
- 對於特定或不特定人士做不實指控或謊報、隱匿實情，致使公務人員於文書登載不實必須擔負法律責任，是否清楚？
- 你於115年09月12日第一次警詢筆錄的陳述是否實在？
- 是否需要親友或社工師到場陪同製作筆錄？
- 案件涉及性影像時，你是否有想指定性別員警受理？現由一名女警對你詢問及製作筆錄，你是否同意？

### 2.2 基礎事實與指認

- 是否知悉該犯罪嫌疑人（被告）的長相？穿著特徵？及其身分資料？
- 警方提供指認犯罪嫌疑人紀錄，編號一至六號中，何者為本案犯嫌？（犯嫌可能不在指認表中）
- 你於何時、何地如何遭人傷害（或遭竊、遭毀損等）？因何事與對方起爭執？請詳述案發經過。
- 現場有無裝設監視器或其他人見聞？時間有無誤差？有無聯絡方式？有無佐證資料可提供警方？或有利事證須請警方協助調查？
- 你是否知悉於警詢筆錄中做不實陳述須負法律責任？

### 2.3 法條釋明與定性確認

- 你是否知悉依刑事訴訟法第237條告訴期為六個月？是否曾經提告此案過？或是否曾經撤回告訴過？
- 你是否知悉依刑事訴訟法第238條：告訴乃論之罪，告訴人於第一審辯論終結前，得撤回其告訴。撤回告訴之人，不得再為同一件事提出告訴？
- 依北市警刑偵字第1133115422號所分，按刑法第337條所規定侵占遺失物、漂流物或其他離本人持有之物，係指該物並非出於本人意思而脫離本人持有，且尚未落入任何人管領而持有之物，亦即依法律及一般社會通念尚難謂該物已與他人具有事實上監督及管領之支配關係而言。行為人取得該物時，該物若尚在持有權人支配管領所及範圍，應論以竊盜之罪，反之則應論以刑法第337條侵占遺失物、漂流物或其他離本人持有之物罪（最高法院110年度台上字第3477號判決意旨參照）。本案被害人將其雨傘置放於自家店外傘架上，該物仍在其支配管領範圍內，而遭不明人士取走，應受理竊盜罪（列為第一案類）為宜。請問你是否清楚？要提告何告訴？
- 依性騷擾防治法第18條規定，因本案係權勢性騷擾以外之性騷擾事件，任一方當事人如有意願進行調解，得以書面或言詞向直轄市、縣（市）社政主管機關申請調解，你是否知悉？你是否有意願申請調解？
- 依據犯罪被害人權益保障法第40條規定，應於製作筆錄時告知第35條、第36條規定（詳如保護命令告知書），是否清楚？有無註明意見？

### 2.4 收尾式（意願與送達）

- 你是否要提出告訴？提出何種告訴？是否曾向其他警察單位報案（有無開立證明單或未獲受理緣由過程）？是否附帶民事求償？有無與嫌犯和解或調解之意願？
- 如警方通知涉嫌人後，你是否同意與對方和解？
- 你是否需要鑑識小隊採證？
- 案件後續司法文書有無指定收件之處所？是否能提供聲請變更送達處所狀？
- 你是否確定要撤回告訴？為何你要撤回告訴？請詳述原因。撤回告訴狀與和解書是否由你親自填寫？是否能提供給警方？
- 贓物認領保管單是否為你本人確認無誤後親自簽名？
- 你是否要對該恐嚇之人（或詐欺、跟蹤騷擾等相對人）提出告訴？欲提出何種告訴？
- 你是否要對詐欺你的人提出詐欺告訴？有無與嫌犯和解或調解之意願？
- 你是否同意由警察機關現場協助你安裝警政服務APP或追蹤165全民防騙臉書粉絲專頁，以利接收最新反詐騙資訊？
- 文書送達地址為何？
- 以上所言是否實在（屬實）？有無其他補充陳述之意見？
- 以上內容是否為你自由意識下所為之陳述？

## 3. 證人通用筆錄骨架

（需特別包含拒絕證言事由之告知）

### 3.1 起手式（程序與權利）

- 你上述年籍資料是否正確？是否為你本人？有無攜帶身分證明文件？
- 真實姓名對照表內之資料是否正確？是否為你本人？
- 你向警方表示你係為美國人士，請問你的中文聽、說、讀、寫能力如何？
- 你現在精神狀況如何？是否可以製作筆錄？是否需要家屬或社工到場陪同？
- 是否領有身心障礙證明或經醫囑使用精神藥物？類別、鑑定向度及障礙程度為何？
- 你今(12)日因何事接受警方製作筆錄？
- 公司地址為何？現任何職？是否有公司授權委託書？
- 你的文書送達地址為何？

### 3.2 基礎事實與指認

- 你與被害人為何種關係？如何認識？
- 妳與涉嫌人是否認識？何種關係？有無任何仇恨、糾紛？
- 是否知道對方年籍資料、聯絡方式？與對方是否認識？有無仇恨或糾紛？
- 當被害人遭毀損時，你是否在場？請說明事情過程？
- 本事件發生地的場所主人（管理人）為何人？事件發生後你有無告知該人？該場所主人（管理人）作何處置？
- 刑事相驗：你於何時、何地、如何發現當事人狀況？過程為何？請詳述之。

### 3.3 法條釋明與定性確認

- 請問你是否現為或曾為犯罪嫌疑人之配偶、直系血親、三親等內之旁系血親、二親等內之姻親或家長、家屬者？
- 請問你是否與犯罪嫌疑人訂有婚約者？
- 請問你是否現為或曾為犯罪嫌疑人之法定代理人，或現由或曾由犯罪嫌疑人為其法定代理人者？
- 你是否知悉使公務員登載不實須負相關責任？
- 對於特定或不特定人士做不實指控或謊報、隱匿實情，致使公務人員於文書登載不實必須擔負法律責任，是否清楚？

### 3.4 收尾式（意願與送達）

- 上述所說是否實在？有無其他意見補充？
- 以上所言是否屬實？有無其他補充意見？
- 以上內容是否為你自由意識下所為之陳述？
- 你於115年09月12日第一次警詢筆錄的陳述是否實在？
- 你是否要提出申訴？對何人提出？（如為性別平等工作法可對雇主提出申訴）
- 你是否要提出性騷擾罪（性騷擾防治法第25條）或其他刑事告訴？對何人提出？
- 文書送達地址為何？

## 4. 系統整合建議

未來 LLM 生成筆錄時，應依下列順序組裝「通用骨架 + PAIR 區辨問句」：

1. 先輸出 對應角色的 1.1 起手式（身分核對 → 權利告知 → 程序告知 → 夜間偵訊同意等），不得省略。
2. 輸出 1.2 基礎事實與指認（客觀事實：時間、地點、人物、指認監視器等）。
3. **在 1.2 與 1.3 之間，無縫插入 PAIR 區辨問句（來自 `B_master_case_studies.yaml`）**：即針對該案類（竊盜 vs 侵占、傷害 vs 公然侮辱等）的「法律區辨要素」提問，例如主觀犯意、所有權變動、支配管領範圍、犯意聯絡等。這些問句用來涵攝構成要件，不可提前至起手式或延後至收尾。
4. 輸出 1.3 法條釋明與定性確認（引用函釋／判決／法條，向當事人確認法律定性與告訴類型），例如：
   - 北市警刑偵字第 1133115422 號所分 + 刑法第 337 條 + 最高法院 110 年度台上字第 3477 號 → 請問你是否清楚？要提告何告訴？
   - 毒品危害防制條例第 17 條、就業服務法第 60 條、性騷擾防治法第 18 條、犯罪被害人權益保障法第 40 條等。
5. 最後輸出 1.4 收尾式（提告 / 撤回告訴、附帶民事求償、調解 / 和解意願、指定送達處所、筆錄確認與其他意見補充）。

特別原則：
- 拒絕證言事由之告知（證人筆錄 3.3：配偶、直系血親、三親等內旁系血親、二親等內姻親、家長／家屬、婚約、法定代理人）必須在證人角色中完整保留，不可省略。
- 法條釋明類問句（1.3 / 2.3 / 3.3）是實務重點：不得以一般性法律說明代換，必須保留函號、條號與判決字號之引用。
- 原始 `extracted_excel_questions.md` 不得修改；本報告僅為分析產物。
