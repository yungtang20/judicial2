## 4. 缺漏檢視與 Phase 2 補齊建議
經檢視目前 46 組 PAIR，已涵蓋絕大多數財產、人身、妨害秩序與性犯罪之核心爭點。但若以「第一線執法最常遇到之移送困境」為標準，建議於 **Phase 2** 優先補齊以下 3 組極具實務價值之真爭點：

### 🔹 建議新增 PAIR-A：幫助詐欺 vs 一般詐欺共犯
- **真爭點**：行為人主觀上僅有「幫助他人犯罪」之不確定故意，抑或已與正犯有「共同實施詐欺」之犯意聯絡與行為分擔？
- **底層事實問句方向**：「你把帳戶交給對方時，對方是說要『借用一下』，還是承諾會『分你多少利潤』？」、「對方拿你的帳戶去做什麼，你有沒有具體過問或參與討論？」

### 🔹 建議新增 PAIR-B：一般洗錢 vs 前置財產犯罪 (如詐欺/竊盜)
- **真爭點**：行為人之收受、搬運行為，是前置犯罪之「當然延伸（事後不可罰）」，抑或另有「掩飾、隱匿犯罪所得去向」之獨立洗錢故意？
- **底層事實問句方向**：「你拿到這筆錢後，是立刻拿去繳自己的房租/日常花費，還是刻意分成多筆小額轉給不同人，或購買虛擬貨幣？」

### 🔹 建議新增 PAIR-C：竊佔 vs 竊盜
- **真爭點**：行為人破壞他人持有並建立新持有之客體，為「不動產」（如土地、建物）抑或「動產」？
- **底層事實問句方向**：「你佔用這塊土地或房間後，是否有加裝門鎖、圍籬或改變原有設施，排除原權利人使用？」
