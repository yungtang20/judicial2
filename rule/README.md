# 法律案件工作台規則索引

本目錄保存經使用者確認的產品規則。後續設計、實作、測試及驗收均應引用本目錄中的規則，不得以舊文件或既有程式行為覆蓋。

## 已確認規則

1. [條陳摘要與顯示規則](./statement-summary-rule.md)
   - 正式條陳的案件摘要最多 500 個字。
   - 500 個字均可在網頁完整顯示。
2. [筆錄八頁限制規則](./interview-page-limit-rule.md)
   - 每一個角色的每一份筆錄最多 8 頁。
3. [公司筆錄角色規則](./company-template-role-rule.md)
   - 公司筆錄均已有對應角色。
   - 公司原始問句須依其角色及原順序使用。
4. [Gate 2 法律路由人工選擇規則](./gate2-legal-route-selection-rule.md)
   - 候選罪章與 child legal route 分開保存並原子提交。
   - 路由選擇須經人工確認，且不得冒充 route-specific 問句已完成。

## 規則優先級

- 本目錄所載的使用者確認規則，優先於專案內仍記載「100 字摘要」或以整案合計頁數計算的舊說明。
- 法律規定、有效的公司程序及人工核准要求仍應保留。
- 候選罪章僅為調查方向，不得因本目錄規則而變成犯罪成立判斷。

## 變更原則

- 規則有異動時，應新增版本紀錄或明確修訂本文件。
- 不得只修改程式而未同步更新規則及測試。
- 不得以測試通過取代法律內容或公司程序的人工確認。
