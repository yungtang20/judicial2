# 01 核心原則

本檔案只寫三項鐵則及其釋義。**不寫問句、不寫流程**。

---

## 鐵則一：單一來源（Single Source of Truth）

**規則**：同一條規則、同一句問句，**只存在一個檔案**。其他檔案若要用，寫引用編號，不複製貼上。

**引用格式**：

```text
（見 05-2 涉嫌人通用 第 1 題）
（見 06-3 性騷擾行為人例稿 SXH-ACT-001）
```

**禁止範例**：
- ❌ 在 06-3 內直接貼上「你是何時認識被害人？」
- ❌ 在 07 內重複 05-1 已列之 5 個基本身份題。

**允許例外**：僅「權限告知全文」與「簽名欄位」兩類固定文字允許於 03、10 各自維護一次；其他檔案引用「見 03 第 X 段」即可。

## 鐵則二：編號系統（Traceable ID）

**格式**：`[角色]-[案件類型]-[來源]-[序號]`

**代號對照**：

| 片段 | 意義 |
|---|---|
| P | 被害人 (Victim) |
| S | 涉嫌人 (Suspect) |
| A | 行為人 (Actor) |
| W | 證人 (Witness) |
| R | 告訴人/告發人/關係人 (Relator) |
| SX | 性影像 |
| SXH | 性騷擾 |
| GS | 跟蹤騷擾 |
| BH | 違反保護令 |
| QT | 竊盜 |
| JD | 酒駕 |
| ZH | 詐欺 |
| DP | 毒品 |
| GEN | 通用（跨案件） |
| EXG | 例稿原生問句 |
| ADD | 增加問句 |
| RGT | 權利告知 |
| FMT | 格式骨架 |

**例**：

```text
P-SX-GEN-001  被害人 × 性影像 × 通用 × 第 001 題
S-SXH-EXG-001  涉嫌人 × 性騷擾 × 例稿 × 第 001 題
W-GEN-ADD-003  證人 × 通用 × 增加 × 第 003 題
```

**規則**：
- 序號一律三位數、從 001 起，**跳號即視為已廢棄，不得複用**。
- 序號跨版本永不回滾；刪除問句只標 `[DEPRECATED]`，不改寫原編號。
- 每個問句在**其所在檔案**內**出現一次且僅一次**。

## 鐵則三：版本控制從第一天開始

**檔案開頭強制欄位**：

```text
版本：X.Y
日期：YYYY-MM-DD
作者：
變更紀錄：
- X.Y (YYYY-MM-DD) 摘要
```

**規則**：
- 修改檔案必增版本號，日期為**變更日**（非原始建立日）。
- 變更紀錄只追加、不刪除、不改寫歷史條目。
- 跨檔案引用若目標檔案升版破壞相容（例：05-2 刪題），引用方同批次升版並註明。
- 「作者」欄位可寫：真人姓名、`AI 初稿`、`AI 覆核`、`人工覆核` 之一或多個，用 `/` 分隔。

## 附：物件區分（防止角色混用）

| 物件 | 屬警訊階段 | AI 是否可生成 |
|---|---|---|
| 問句 | 訊問官提出 | ✅ 可（限引用） |
| 答句 | 被訊問人回答 | ❌ 嚴禁 |
| 筆錄格式骨架 | 訊問官排版 | ✅ 可（依 13） |
| 權利告知 | 訊問官宣讀 | ⚠ 可引用 03 原文，不改寫 |
| 法律判斷 | 檢察官/法官 | ❌ 嚴禁 |

## 附：三條不可變動語氣

1. **訊問階段**（涉嫌人）用「你是……嗎？」、不得暗示答案。
2. **詢問階段**（被害人/證人）用「你能說明……嗎？」、不得誘導。
3. **權限告知**用 03 之**法定原文**、不得潤飾。
