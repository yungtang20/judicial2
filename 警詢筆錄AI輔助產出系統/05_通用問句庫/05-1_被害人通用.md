# 05-1 被害人（P）通用問句庫

本檔案只寫**跨案件通用**、且**只對被害人**成立之問句。**案件特化問句放 06，不要放這裡。**

語氣：詢問式（見 01 附三條不可變動語氣第 2 項）。
編號規則：`P-GEN-???`（案件代號留為 GEN，序號三位數，跳號即廢棄）。

---

## A. 身份與聯絡

| 編號 | 問句 |
|---|---|
| P-GEN-001 | 請問你的姓名字號？ |
| P-GEN-002 | 請問你的身分證字號？ |
| P-GEN-003 | 請問你的出生日期？ |
| P-GEN-004 | 請問你的現住地址？ |
| P-GEN-005 | 請問你的聯絡電話？ |
| P-GEN-006 | 請問你目前的職業？ |
| P-GEN-007 | 請問你最近一年是否有遷徙？如有，請問何時遷至現址？ |
| P-GEN-008 | 請問你是否有法定代理人？如有，請問姓名為何？ |

## B. 案件基本事實

| 編號 | 問句 |
|---|---|
| P-GEN-010 | 請問你此次是針對哪一件事情到警局說明？ |
| P-GEN-011 | 請問這件事情發生的時間？ |
| P-GEN-012 | 請問這件事情發生的地點？ |
| P-GEN-013 | 請問你與相對方（行為人／涉嫌人）是何種關係？ |
| P-GEN-014 | 請問你是在何種場合認識相對方？ |
| P-GEN-015 | 請問你與相對方的關係維持多久？ |

## C. 事件經過（骨架）

| 編號 | 問句 |
|---|---|
| P-GEN-020 | 請你按時間順序說明整個事件的經過。 |
| P-GEN-021 | 事件發生前，相對方是否有前兆行為或言論？請描述。 |
| P-GEN-022 | 事件發生的當下，你在哪裡？當時在何種狀態？ |
| P-GEN-023 | 現場除相對方外，還有其他人嗎？其身分為何？ |
| P-GEN-024 | 事件發生後，你的第一時間反應是什麼？ |
| P-GEN-025 | 事件後你是否有通報？通報對象為何？ |
| P-GEN-026 | 事件後你是否有就醫、驗傷、通報社會單位或其他動作？ |

## D. 主觀認知與感受

| 編號 | 問句 |
|---|---|
| P-GEN-030 | 請問你當時是否同意相對方的作為？ |
| P-GEN-031 | 請問你是否有表達過不同意的意思？如何表達？ |
| P-GEN-032 | 請問事件對你有造成何種傷害或影響？ |
| P-GEN-033 | 請問你目前身心健康狀況如何？ |

## E. 證據與物件

| 編號 | 問句 |
|---|---|
| P-GEN-040 | 請問事件過程中是否產生任何物件、文件、訊息、影像或錄音？ |
| P-GEN-041 | 請問這些物件或訊息你目前是否保留？存放於何處？ |
| P-GEN-042 | 請問你願意向警方提供這些資料嗎？ |
| P-GEN-043 | 請問事件現場是否設有監視器或可取得影像？ |
| P-GEN-044 | 請問現場是否有其他見證人？其身分為何？ |

## F. 告訴與後續

| 編號 | 問句 |
|---|---|
| P-GEN-050 | 請問你是否要提出告訴？ |
| P-GEN-051 | 請問你是否希望對告訴內容附加意見？ |
| P-GEN-052 | 請問你是否有指定代理告訴之律師？ |
| P-GEN-053 | 請問你是否希望進入社會保護或輔導程序？ |
| P-GEN-054 | 請問你是否希望本筆錄以匿名或去識別方式處理？ |

## G. 告知與確認

| 編號 | 問句 |
|---|---|
| P-GEN-060 | 你以上所述是否完全符合事實？ |
| P-GEN-061 | 你是否有需要補充的地方？ |
| P-GEN-062 | 你是否同意本筆錄以目前內容定稿？ |
| P-GEN-063 | 你是否有需要撤回或修正的內容？ |

---

## 附：使用建議

- 首段固定取 A（001–008），確保身份識別。
- 中段依案件類型（見 06）疊加專用問句，勿於本檔案重複。
- 尾段固定取 G（060–063），確保程序完整。
- 本檔案所有問句均為**引用來源**，其他檔案不得重複貼上。
