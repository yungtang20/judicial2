# 05-2 涉嫌人（S）通用問句庫

本檔案只寫**跨案件通用**、且**只對涉嫌人**成立之問句。語氣為訊問式（見 01 附三條不可變動語氣第 1 項）。
編號規則：`S-GEN-???`。

**前置條件**：本檔案之問句**不得**在 03 權利告知完成前使用。訊問官須先完成權利告知（見 03 之 RGT 段）。

---

## A. 身份與聯絡

| 編號 | 問句 |
|---|---|
| S-GEN-001 | 你的姓名為何？ |
| S-GEN-002 | 你的身分證字號為何？ |
| S-GEN-003 | 你的出生日期為何？ |
| S-GEN-004 | 你的現住地址為何？ |
| S-GEN-005 | 你的聯絡電話為何？ |
| S-GEN-006 | 你的職業為何？ |
| S-GEN-007 | 你是否曾受過警詢、偵查或司法處理？請說明。 |
| S-GEN-008 | 你是否有律師陪同或欲委任辯護人？ |

## B. 權利告知確認

| 編號 | 問句 |
|---|---|
| S-GEN-010 | 你是否已聽懂剛才告知你之權利？ |
| S-GEN-011 | 你是否欲行使上述任一權利？ |
| S-GEN-012 | 你是否同意本次訊問全程錄音錄影？ |
| S-GEN-013 | 你是否欲在訊問過程中隨時終止或休息？ |

## C. 到案經過

| 編號 | 問句 |
|---|---|
| S-GEN-020 | 你是何時到案的？ |
| S-GEN-021 | 你是以何種方式到案？（自首、傳訊、拘提、逮捕、其他） |
| S-GEN-022 | 到案前你是否與他人聯絡過？與誰聯絡？談及何事？ |
| S-GEN-023 | 到案時你是否持有與案件相關之物件？請說明。 |

## D. 事件基本事實（訊問式）

| 編號 | 問句 |
|---|---|
| S-GEN-030 | 你是何時認識被害人？ |
| S-GEN-031 | 你是如何認識被害人的？ |
| S-GEN-032 | 你與被害人之間的關係是什麼？ |
| S-GEN-033 | 你是何時接觸本案所涉之時間點與地點？ |
| S-GEN-034 | 你於該時間該地點在做何事？ |
| S-GEN-035 | 現場除你以外是否還有其他人？其人身分為何？ |
| S-GEN-036 | 你是否承認參與本案所涉之行為？ |
| S-GEN-037 | 你參與的具體行為為何？ |
| S-GEN-038 | 你為何實施上述行為？ |
| S-GEN-039 | 你實施上述行為時有無共同犯意聯絡或分工？ |

## E. 物件、證據

| 編號 | 問句 |
|---|---|
| S-GEN-040 | 你現在身上、住處或所有物中，是否有與本案相關之物件？ |
| S-GEN-041 | 上述物件是否願意或依法交付？ |
| S-GEN-042 | 你是否與被害人有任何通訊紀錄？保存在何處？ |
| S-GEN-043 | 你是否曾取得、保存、散佈與本案相關之影像、訊息或文件？ |

## F. 主觀認知

| 編號 | 問句 |
|---|---|
| S-GEN-050 | 你實施行為時是否知道被害人年齡？ |
| S-GEN-051 | 你實施行為時是否知道被害人同意或不同意？ |
| S-GEN-052 | 你實施行為時是否知道該行為屬違法？ |
| S-GEN-053 | 你是否為避免被害人傷害而實施行為？ |

## G. 補救與告知

| 編號 | 問句 |
|---|---|
| S-GEN-060 | 你是否已對被害人補償或道歉？ |
| S-GEN-061 | 你是否願意補償被害人損失？ |
| S-GEN-062 | 你是否了解上述行為可能成立之犯罪？ |

## H. 確認與終結

| 編號 | 問句 |
|---|---|
| S-GEN-070 | 你以上所述是否完全符合事實？ |
| S-GEN-071 | 你是否有需要補充的地方？ |
| S-GEN-072 | 你是否有需要撤回或修正的內容？ |
| S-GEN-073 | 你是否同意本筆錄以目前內容定稿？ |
| S-GEN-074 | 你是否願意在本筆錄上簽名（或按指印）確認？ |

---

## 附：訊問式語氣對照

- 禁止使用「你是不是同意做……？」（預設肯定）。
- 應使用「你是……嗎？」（開放式二值）。
- 涉及主觀意圖者，先問客觀事實、後問主觀認知；避免先問「為什麼」。
