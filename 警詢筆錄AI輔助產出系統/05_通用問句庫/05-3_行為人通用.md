# 05-3 行為人（A）通用問句庫

本檔案只寫**跨案件通用**、且**只對行為人**成立之問句。**行為人未必為涉嫌人**；例如行政告知、民事告知、輔導告知情境。
編號規則：`A-GEN-???`。

---

## A. 身份與聯絡

| 編號 | 問句 |
|---|---|
| A-GEN-001 | 你的姓名為何？ |
| A-GEN-002 | 你的身分證字號為何？ |
| A-GEN-003 | 你的出生日期為何？ |
| A-GEN-004 | 你的現住地址為何？ |
| A-GEN-005 | 你的聯絡電話為何？ |
| A-GEN-006 | 你的職業為何？ |

## B. 告知情境確認

| 編號 | 問句 |
|---|---|
| A-GEN-010 | 你此次為何接受本次告知？（行政告知、民事告知、警詢告知、其他） |
| A-GEN-011 | 你是否已聽懂告知目的與範圍？ |
| A-GEN-012 | 你是否有欲行使之程序性權利？ |

## C. 行為基本事實

| 編號 | 問句 |
|---|---|
| A-GEN-020 | 你與被害人之間的關係為何？ |
| A-GEN-021 | 你是在何時接觸被害人？ |
| A-GEN-022 | 你是在何地接觸被害人？ |
| A-GEN-023 | 你與被害人接觸的具體行為為何？ |
| A-GEN-024 | 你實施上述行為時是否有其他人？其人身分為何？ |
| A-GEN-025 | 你實施上述行為時是否取得被害人同意？ |
| A-GEN-026 | 被害人是否曾表達不同意？ |

## D. 物件與證據

| 編號 | 問句 |
|---|---|
| A-GEN-030 | 你與被害人之間是否有通訊紀錄？ |
| A-GEN-031 | 你是否曾向他人傳給、展示或提供與被害人相關之影像或訊息？ |
| A-GEN-032 | 上述影像或訊息目前存放於何處？ |
| A-GEN-033 | 你是否願意向本次告知機關提供相關資料？ |

## E. 主觀認知與補救

| 編號 | 問句 |
|---|---|
| A-GEN-040 | 你實施行為時是否知道該行為對被害人可能造成影響？ |
| A-GEN-041 | 你是否曾向被害人致歉？如何致歉？ |
| A-GEN-042 | 你是否願意補救被害人損失？ |
| A-GEN-043 | 你是否願意接受輔導、教育或處理程序？ |

## F. 確認與終結

| 編號 | 問句 |
|---|---|
| A-GEN-050 | 你以上所述是否完全符合事實？ |
| A-GEN-051 | 你是否有需要補充的地方？ |
| A-GEN-052 | 你是否有需要撤回或修正的內容？ |
| A-GEN-053 | 你是否同意本筆錄以目前內容定稿？ |

---

## 附：與 05-2 差異

- **無訊問式語氣**：05-2 使用訊問式，本檔案使用告知式。
- **無到案經過段**：行為人不必然到案。
- **無「是否承認」**：行為人通常已知事實，重點為確認與補救。
