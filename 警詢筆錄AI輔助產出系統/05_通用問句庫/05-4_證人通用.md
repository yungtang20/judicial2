# 05-4 證人（W）通用問句庫

本檔案只寫**跨案件通用**、且**只對證人**成立之問句。**證人不得訊問**（見 01 附三條不可變動語氣第 2 項）。
編號規則：`W-GEN-???`。

---

## A. 身份與聯絡

| 編號 | 問句 |
|---|---|
| W-GEN-001 | 請問你的姓名字號？ |
| W-GEN-002 | 請問你的身分證字號？ |
| W-GEN-003 | 請問你的出生日期？ |
| W-GEN-004 | 請問你的現住地址？ |
| W-GEN-005 | 請問你的聯絡電話？ |
| W-GEN-006 | 請問你的職業？ |

## B. 告知與告知義務

| 編號 | 問句 |
|---|---|
| W-GEN-010 | 你是否了解證人具告知義務？ |
| W-GEN-011 | 你是否了解對本案有告知義務者，若無正當理由不告知將受處罰？ |
| W-GEN-012 | 你與本案當事人是否有關係？ |
| W-GEN-013 | 你有無依法得拒答之事由？ |

## C. 事件知悉經過

| 編號 | 問句 |
|---|---|
| W-GEN-020 | 你是如何得知本案事實？（親歷、聽聞、閱覽、其他） |
| W-GEN-021 | 你是在何時得知？ |
| W-GEN-022 | 你是在何地得知？ |
| W-GEN-023 | 你親自觀察到的部分為何？ |
| W-GEN-024 | 你由他人轉述所得的部分為何？轉述者為何人？ |
| W-GEN-025 | 你觀察事件時，現場除當事人外還有何人？其人身分為何？ |
| W-GEN-026 | 你觀察事件時，現場的光線、距離、視角為何？ |

## D. 事件細節

| 編號 | 問句 |
|---|---|
| W-GEN-030 | 事件發生前後，你是否有與當事人交談？ |
| W-GEN-031 | 事件發生前後，你是否有與他證人交談？ |
| W-GEN-032 | 事件過程中，你是否發現任何物件、痕跡、訊息、影像？ |
| W-GEN-033 | 上述物件或訊息你目前是否保留？存放於何處？ |
| W-GEN-034 | 你是否願意向警方提供這些資料？ |

## E. 關係與利害

| 編號 | 問句 |
|---|---|
| W-GEN-040 | 你與被害人之間有無利害關係？ |
| W-GEN-041 | 你與涉嫌人之間有無利害關係？ |
| W-GEN-042 | 你是否有其他影響證詞客觀性的事由？ |

## F. 確認與終結

| 編號 | 問句 |
|---|---|
| W-GEN-050 | 你以上所述是否完全符合你所知事實？ |
| W-GEN-051 | 你是否有需要補充的地方？ |
| W-GEN-052 | 你是否有需要撤回或修正的內容？ |
| W-GEN-053 | 你是否同意本筆錄以目前內容定稿？ |

---

## 附：不得問之項目

- 不得問「為何犯罪」、動機判斷。
- 不得問「你猜他會不會是……」（誘導）。
- 不得問「被害人有沒有誘惑你」（價值判斷）。
- 不得問對法律評價：「他的行為是不是犯罪？」。
