# 05-5 告訴人／告發人／關係人（R）通用問句庫

本檔案只寫**跨案件通用**、且**只對告訴人、告發人或關係人**成立之問句。
編號規則：`R-GEN-???`。

---

## A. 身份與聯絡

| 編號 | 問句 |
|---|---|
| R-GEN-001 | 請問你的姓名字號？ |
| R-GEN-002 | 請問你的身分證字號？ |
| R-GEN-003 | 請問你的出生日期？ |
| R-GEN-004 | 請問你的現住地址？ |
| R-GEN-005 | 請問你的聯絡電話？ |
| R-GEN-006 | 請問你的職業？ |

## B. 身分與關係

| 編號 | 問句 |
|---|---|
| R-GEN-010 | 你與被害人之間為何種關係？ |
| R-GEN-011 | 你與被害人之間的關係維持多久？ |
| R-GEN-012 | 你是以何種身分到案？（告訴人、告發人、關係人、其他） |
| R-GEN-013 | 你提出告訴或告發時，被害人是否知情？ |
| R-GEN-014 | 被害人是否同意你代為提出告訴？ |

## C. 告知情境

| 編號 | 問句 |
|---|---|
| R-GEN-020 | 你是否了解告訴與告發之差異？ |
| R-GEN-021 | 你是否了解告訴具有撤回的可能？ |
| R-GEN-022 | 你是否了解告發內容屬告知機關處理？ |

## D. 事實來源

| 編號 | 問句 |
|---|---|
| R-GEN-030 | 你是如何得知本案事實？（親歷、聽聞、閱覽、其他） |
| R-GEN-031 | 你是在何時得知？ |
| R-GEN-032 | 你是在何地得知？ |
| R-GEN-033 | 你親自經歷的部分為何？ |
| R-GEN-034 | 你由他人轉述所得的部分為何？轉述者為何人？ |
| R-GEN-035 | 上述轉述是否為書面、書信、通訊軟體或口頭？ |

## E. 事實內容

| 編號 | 問句 |
|---|---|
| R-GEN-040 | 事件發生的時間為何？ |
| R-GEN-041 | 事件發生的地點為何？ |
| R-GEN-042 | 事件過程為何？ |
| R-GEN-043 | 你於事件現場是否親歷？ |
| R-GEN-044 | 事件過程中是否產生任何物件、訊息、影像或錄音？ |
| R-GEN-045 | 上述物件目前是否存在？存放於何處？ |
| R-GEN-046 | 你是否願意向警方提供上述資料？ |

## F. 告訴意願與後續

| 編號 | 問句 |
|---|---|
| R-GEN-050 | 你是否要對本案提出告訴？ |
| R-GEN-051 | 你是否希望告訴內容限制於特定人？ |
| R-GEN-052 | 你是否希望告訴內容附帶民事求償或意見？ |
| R-GEN-053 | 你是否希望案件進入保護或輔導程序？ |

## G. 確認與終結

| 編號 | 問句 |
|---|---|
| R-GEN-060 | 你以上所述是否完全符合你所知事實？ |
| R-GEN-061 | 你是否有需要補充的地方？ |
| R-GEN-062 | 你是否有需要撤回或修正的內容？ |
| R-GEN-063 | 你是否同意本筆錄以目前內容定稿？ |

---

## 附：告訴人 vs. 告發人 vs. 關係人

| 身分 | 是否具告權 | 是否具程序上權利 | 常見案件 |
|---|---|---|---|
| 告訴人 | 是 | 有（撤訴、和解、附帶民事） | 親密關係犯罪、告訴乃論 |
| 告發人 | 否 | 無（僅提供資訊） | 公共利益犯罪 |
| 關係人 | 依情況 | 部分（陪伴、諮詢） | 家暴、兒少案件 |
