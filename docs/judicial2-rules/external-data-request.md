# 受理單位資料索取清單

狀態：`PENDING_EXTERNAL_RESPONSE`

本檔只定義索取內容與驗收條件。尚未向任何外部單位送出請求。

## 1. 條陳模板

請各權責單位提供目前有效版本：

- 吳興所：受理報告、告發報告。
- 三張所：受理報告、告發報告。
- 信義分局：受理報告、告發報告。

每份資料須包含：

- 文件名稱與適用單位。
- 文件類型。
- 版本或施行日期。
- 必填欄位與選填欄位。
- 欄位填寫規則。
- 去識別化範例。
- 提供者或權責窗口。
- 可否納入系統及使用限制。
- 收件日期與傳輸管道。
- 收件檔案 SHA-256。
- 保存期限、保存限制與刪除要求。

驗收條件：六種「單位 × 文件類型」組合均有資料，或由權責單位明確確認共用同一模板。

## 2. 案號格式清單

請提供下列識別碼的正式格式、範例與驗證規則：

- Z 字 e 化案號。
- 165 案號。
- 婦幼案號。
- 證明單號。
- 通報案號。
- 其他目前使用中的案號或識別碼。

每一類須包含：

- 正式名稱與用途。
- 發號單位。
- 字首、位數、年份與分隔符規則。
- 是否允許跨行、空白或全形字元。
- 去識別化有效範例與無效範例。
- 是否能單獨證明案件已受理。
- 格式變更的生效日期。
- 來源人身分、收件日期與傳輸管道。
- 收件檔案 SHA-256、使用授權與保存限制。

驗收條件：資料足以建立 C-R21 的正規化與格式檢核規則，且不以推測補齊未知格式。

## 3. 通緝書內容取得方式

請權責單位確認：

- 路由 B 執行時可取得的正式資料來源。
- 系統可接收全文、節錄、結構化欄位或僅可人工閱覽。
- 最少必要欄位。
- 通緝書未附時的標準處理。
- 是否允許以其他正式資料替代。
- 個資、保密、留存與存取權限限制。
- 來源人身分、收件日期、傳輸管道與檔案 SHA-256。
- 使用授權、保存期限與刪除要求。

驗收條件：可據以實作 v18 已決定的「通緝書必附」規則，並明確定義正式取得方式、最少必要欄位與缺件流程，且不擴張系統的資料存取權限。

## 外部資料三格查證卡

- 問句：已明確限定單位、文件類型、案號種類與路由 B。
- 證據：`UNKNOWN`，等待權責單位提供可回查資料。
- 痕跡：本檔為索取規格；實際往來、日期與提供者尚未產生。
